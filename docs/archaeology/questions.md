## 单题处理流程

1. 原样或忠实摘要记录作者回答，并注明日期。
2. 列出回答中可由仓库验证的时间、文件、提交和行为。
3. 查找反例、分支差异与同期文档，保留不一致之处。
4. 将确认内容写入时期文档，把推断和未知项继续留在台账。
5. 在问题状态改为 `已写入` 时注明目标文档与关键证据。
