# 口述史料

本目录保存 Git、源码和提交说明无法重建的作者原话，主要涉及动机、当时的理解、贡献来源和
工作方式。它不是新的时期叙事；`periods/`、`evidence/` 与 `essays/` 仍负责经过交叉核对的历史
结论。

口述材料按以下边界使用：

- 回答原文与后来的 Git 核查分开排版；
- 保留“我记得”“应该”“大概”等不确定表达；
- 口述可解释动机和个人感受，不能替代对象级技术验证；
- 会话中的 assistant 总结不作为作者原话保存；
- 只选无法由 Git 重建、且会影响主线理解的回答，不保存完整聊天记录。
