# ToyCCompiler 时期

## 研究范围

从 2026-07-04 的独立根提交到 2026-07-11 的仓库重定向，研究编译器如何脱离 Tinylibc 的应用
语境，集中完成自身编译、汇编、链接和多阶段收敛。另设开发工具线索，考察 Claude Code 与
DeepSeek API 的实际分工，而不从提交署名直接推断贡献比例。
