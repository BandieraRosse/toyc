# 音频设置与验证

> 状态：当前
> 所有者：Rasterfall audio presentation
> 最近核对：2026-10-08

所有权、分组和简化空间效果见[音频架构](../architecture/audio.md)。

## 玩家设置

按 Esc 打开中文暂停菜单，点击“音频设置”或用上下键选择后按 Enter。菜单与玩家界面共用主题、
字号和缩放，绘制与鼠标命中使用同一布局。控制与开发者子页见[暂停菜单与控制设置](player-ui-v2.md#暂停菜单与控制设置)。暂停主菜单最下面两项依次为“返回前哨站”和“退出游戏”。

音频页支持鼠标悬停选择与高亮，上下键选择项目，左右键以 5% 调整音量，也可点击或拖动音量条设置；
动态范围可点击或按 Enter 循环切换，也可使用左右键调整。“试听枪声与换弹”依次播放自身步枪和换弹，
“恢复默认音频设置”恢复全部音量与标准动态范围。点击“返回暂停菜单”或按 Esc 返回，再按 Esc 继续游戏。
悬停切换、点击、调整、确认和返回使用已有界面提示音，响度服从总音量和界面音效设置。
关闭暂停菜单沿玩家输入抑制机制要求已按住的键鼠释放，避免点击继续游戏后立即开火。
CPU 与 GPU Scene 共用页面和输入路径。

要降低枪声但保留换弹、机器和音乐，调整“枪械与爆炸”；只降低自己的枪声则调整“自身枪声”。
总音量控制包括 UI 和机器在内的全部输出，游戏音效不控制音乐与 UI。

正常交互运行自动保存到运行目录的 `rasterfall_audio.cfg`，使用版本化 ASCII 内容、临时文件与
原子替换。不存在时使用默认值，格式错误不部分应用；写入失败在页面显示，当前声音调节仍生效。
换图、重启音频和 CPU/GPU 切换保留设置。显式有限帧/capture/固定视图诊断默认使用临时设置。

- `RF_AUDIO_SAVE_PATH`：选择独立本地偏好文件，并启用该路径的持久化。
- `RF_AUDIO_NO_SAVE`：禁用偏好读写，使用当前进程的默认/临时设置。
- `RF_UI_AUDIT=1`：沿已有只读诊断路径输出 `AUDIO-AUDIT`，包含暂停页、当前项目、音量、预设与保存错误。

诊断必须将音频偏好隔离到 `tmp/`，不要覆盖玩家偏好。UI 审计、PCM 测试和截图不能证明耳机听感。

## 最近验证

先构建，再运行无需窗口/GPU/音频设备的实际 PCM 混音契约测试：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File windows/NativeCodex.ps1 build
powershell -NoProfile -ExecutionPolicy Bypass -File tools/test_audio.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools/test_weaver_audio.ps1
```

`test_audio.ps1` 连接原生平台文件与数学对象，验证分类调节、自身与世界枪声分离、总静音、
机器分组、声像、并发准入、代际清理、配置覆盖/非法内容拒绝和峰值边界，并对照正式包声音资源/合成回退的枪声峰值与声能。
底层设备输出被测试边界拒绝，所有 PCM 仅在内存生成；测试偏好保存在 `tmp/audio-test/`。

实机按单发、持续连射、多来源交火、机器同时运行的顺序试听。确认枪声有冲击但不长期盖住换弹和反馈，
自身滑块不改变其他来源，左右方向正确，RTS 缩放不导致整体消失；再检查静音、重启保存和返回前哨站。
合成波形与固定样本的自动检查只能证明数值契约，最终默认平衡仍以 Windows 原生设备试听反馈为准。
