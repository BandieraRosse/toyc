## 本轮实现与验收（2026-10-03）

用户要求在改善整体视觉的同时控制性能预算，并授权适量建筑和环境实验区。参考方向仍为
[天空设计研究](../reference/sky-v2-design-study.md)中的前哨站与清透晴空气氛；概念图不是实机完成标准。
本轮按以下四个方向实施，再统一完成 Windows native 验证：

1. **天空稳定与环境气氛**：修复转头时的采样相位跳变，改善云层厚度与云底层次；太阳按显示像素
   求值，朝向太阳时出现平滑柔和光晕。已有固定中点云积分、云密度连续过渡、独立太阳合成与回归候选；
   环境实验区和建筑构图随本轮整合验证。须检查连续转头、云遮太阳及与世界遮挡的关系。
2. **实时光照**：已有连续 16 tap tent PCF、太阳级联边缘混合、半球环境填充和归一化色调映射肩部。
   保持 1024 阴影图、三级太阳加最多两盏聚光灯预算；核对接触阴影、自阴影、暗部法线区分与高亮层次。
   新增环境上下向填充与 HDR 4/8 不提前裁白的行为回归；实际画面与 GPU 成本仍须验收。
3. **通用性能**：已有真实局部 min/max 包围盒和动态层按颜色/纹理格式紧凑打包，保留动画、透明顺序
   及独立主视图/阴影视锥合同。通过同构建 `-ComparePreparation` 交替采样检查上传字节、实际绘制数与
   帧耗时分布，并做像素对照。默认设备选择不指定厂商；单设备结果不外推为所有 GPU 的实测收益。
4. **动漫身体**：RF-C01 V23a 修订肩袖、夹克、工装裤、护膝、手套和靴子，清理身体冗余几何，沿用
   已锁定头部、头发、骨架与动作。已有候选和离线资产合同，当前重点是在新光照下核对轮廓、关节与动作；
   详见[身体候选记录](../archive/character-body-v023a-20261003.md)。本轮不自动扩展贴图、LOD 或完整角色包。

当前状态：上述实现已完成本轮整合验证，逻辑/资产回归、NVIDIA 与 AMD GPU 行为回归、
三个场景逐像素对照及 native WORLD/战斗连续提交通过；固定视角和三轮性能采样已记录于
[本轮现场](../archive/visual-upgrade-20261003.md)。无效绘制减少，但普通限帧场景没有明显整帧提速，
全开长尾仍有反转；稳定 60 FPS 仍是组合场景目标，尚未签收。后续聚焦实机观感与长尾定位。
不引入多帧 pipeline、GI、IBL、多重散射 LUT、世界空气透视或地面云影；CPU 继续保留原实现。

稳定合同分别见[GPU 天空](../architecture/gpu-sky.md)、[GPU 光照](../architecture/gpu-lighting.md)、

## 全景测试与通用缓存结果（2026-10-03）

### Scene 准备优化接续（本轮收尾）

已实现通用 GPU 显示几何常驻、完全相同姿态/敌人几何复用、静态 world freeze 缓存和有界 ID
唯一性校验，并将准备成本及慢帧记录纳入现有性能测试。用户要求本轮尽快收尾并形成一次提交，
详细验证范围和初测见[Scene 准备现场](../archive/scene-preparation-performance-20261003.md)。
初测不等于稳定 60 FPS 签收；当轮未实施多帧 pipeline。以下接续项供后续定向定位，本轮执行顺序以上节为准：

1. **性能复核**：同构建 `-CompareBackend -Capped -Rounds 3`（需要时增至五轮）交替测试当前/全开
   全景，另测默认计算机近景和 1080p；记录逐视角 P95/P99、上传字节与缓存命中率。常规数字关闭
   慢帧诊断，诊断单独复现。先确认默认窗口、展示大多关闭的最差视角，再判断稳定 60 FPS。
2. **角色与动态准备**：统计 pose 求值、palette 打包、附件变换和实际缓存命中率。当前仅同资源
   完全相同输入复用；跨实例 bind/palette 共享、重复姿态采样复用尚未实现。若提前剔除实例，必须
   同时覆盖主视图及阴影视锥，并保持动画历史推进，不按地图或模型名称设置特例。
3. **快照进一步增量化**：当前仍比较 authored 数组并复制完整独立值帧；评估显式内容 generation、
   静态不可变块与动态字段分离，只有在可证明 ownership 和生命周期后才减少剩余复制。
4. **长尾与同步**：结合新增慢帧记录区分准备、蒙皮批次、retire、present 和未归因墙钟时间；
   必要时使用 ETW/GPU 时间线识别驱动等待和系统调度。线程 CPU 差值不能直接当作调度结论。
   多帧 pipeline 按用户决定延期，后续另行设计资源版本、帧槽和延迟边界。
5. **扩展回归与视觉**：补预算耗尽/失败回退、长时间终端内容变化、大量新实例和更多特效下的
   压力测试；继续天空观感迭代。保持来源顺序、阴影和动画连续性，不以隐藏场景内容换取帧率。

已将 FULL SCENE 和当前/全开两种全景巡检纳入原性能实验场，终端移到性能横路路侧，
报告补全展示层、角色、快照等阶段和逐视角统计。操作合同见[性能指南](../guides/rendering-performance.md)。
通用显示几何缓存经过同版本三轮交替测量，平均帧耗时降低约 15%，展示层准备降低约 43%～45%；
八个视角与最终路侧布局逐像素对照一致，逻辑和 native 连续播放/战斗回归通过。
新巡检尚未稳定达到 60 FPS，计算机侧面的 P95/P99 未改善；后续优先处理剩余展示几何准备、
全展示角色准备和快照成本。完整分布与口径见[全景测量现场](../archive/panorama-performance-20261003.md)。

## 园区组合性能结果（2026-10-02）

默认 1280×720、展示大多关闭，在 RTX 3050 Laptop GPU 的四个观察位置各完成五轮正常呈现对照。
每轮 P95 都低于 16.67 ms；各视角 P95 中位数为 11.275～14.812 ms。
合批和剔除保留可见模型与展示内容，像素、光照、天空、世界播放和连续战斗回归通过。
测量口径、完整数据和证据见[本轮现场](../archive/outpost-performance-20261002.md)。

全部展示开启的单轮压力测试 P95 仍为 20.391 ms，不属于已达标范围。
后续根据正常游玩反馈继续处理展示更新/CPU 准备的高分位，并改善远景碎云与云底层次。

## 天空 V2 接续记录（2026-10-02）

以下天空测量是园区组合性能优化前的接续证据，不代表新版本的整帧成本。当前默认天空已提高到 32 步，
并调整云底与太阳遮光；展示层改用逐面颜色/透明度合批，主视图与阴影独立剔除。
操作入口为[园区正常场景采样](../guides/rendering-performance.md#实验园区正常场景采样)。

- 首版已接入 GPU 正常渲染，CPU 旧天空保持原实现；大气为解析近似，尚非多重散射 LUT。
- 前序源码与内嵌 SPIR-V 已完成 Windows native 构建。当时默认每维 1/4 分辨率、24 步；
  1/2 和全分辨率分别为 40、64 步。24 步版本已通过天空/光照回归及死亡、特效压力、160 帧连续战斗检查。
- 本轮将天气覆盖、云群高度、主云团、次级起伏和细节侵蚀分开；远景连续淡出次级起伏与侵蚀，
  复用已有 RGBA 噪声体积，不新增纹理分配。短距太阳探针继续复用低频天气覆盖。
- 增加保守天气斜率界的空区域跳过候选，12 组天气/视角回归与完整扫描逐像素一致。
  正常运行仍默认完整扫描；跳过候选只有诊断开关启用。测量按纯色、候选、完整扫描轮换，避免混淆默认成本。
- RTX 3050 Laptop GPU、1920×1080、固定仰视、每维 1/4 分辨率最新对照：完整扫描 compute
  p50/p95 为 1.933/8.587 ms；候选为 1.954/7.356 ms，配对节省中位数为 -0.004 ms。
  未证明跳过有稳定收益；高分位仍有明显波动，性能验收未完成。先前的不同版本数字不能直接作为同比基线。
- 本机证据：`tmp/sky-v2/shaped/regression.out`、`tmp/sky-v2/shaped/clear-north.png`；
  中间版正常分辨率完整扫描对照在 `tmp/sky-v2/lobes-reference/`，与候选捕获逐像素一致。
  最终构建的死亡、特效压力、160 帧连续战斗检查通过，证据在 `tmp/sky-v2/combat-shaped/`；
  全分辨率档同样通过 12 组跳过对照，日志及雨后、暖光、东向和天顶捕获在 `tmp/sky-v2/final-shaped/`。
  这些临时文件不提交；此前 native 战斗与世界连续播放证据仍保留。
- 后续重点是正常游玩实机观感反馈、性能高分位，以及碎云、远景轮廓与云底层次。
  不扩展窗口尺寸变化或最小化处理。观察入口见[天空指南](../guides/gpu-sky.md)。当前改动尚未提交。

已有光照基础：
