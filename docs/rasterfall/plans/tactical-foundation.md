# 枪战 AI 框架与正式 actor 统一

> 状态：活动
> 所有者：Rasterfall 战术 AI
> 决策日期：2026-10-07

用户审查后要求靶场、策略对抗场、CLI 和预测统一使用正式 Game actor。
本轮执行优先级替代此前“先扩展 Beam、后接入正式角色”的顺序。
当前所有权由[战术架构](../architecture/tactical-ai.md)维护，入口和参数见
[实验指南](../guides/tactical-lab.md)。

## 本轮交付门槛

常态单位碰撞追加范围：真实单位互相阻挡、圆形接触滑行、垂直区间、静态导航隔离和接触近战，
普通游戏与实验共用同一 Game 实现，联机排除。规则/策略版本调整为 3。
原生构建、完整逻辑回归和策略执行/预测一致性已通过，见[单位碰撞收尾](../archive/unit-collision-completion-20261007.md)。
窄门与楼梯的逻辑契约已验证；实机手感以及密集场景的耗时与长尾仍需单独签收。

- Game 唯一拥有身体、武器与伤害，策略只提交意图；靶场玩家正常开火。
- 实验参战者使用真实 actor 身份、正式角色表现、地图碰撞与事件统计。
- 无图形执行和游戏内分阶段执行在同一场景初值下状态一致，预测隔离主世界和 RNG。
- 原生构建、逻辑回归、生命周期、真实遮挡和统计验证；实机交互结果单独报告。
- 退役旧武器/伤害推进与旧训练参数入口，规则版本升级，文档与报告消费端同步。

## 当前交付与后续顺序

用户追加的程序 Block 角色常驻几何优化已完成本轮实现与限定验证：身体、武器、职业装备
保留拓扑，逐帧只求姿态及变换；冻结几何回归、Windows 原生构建、主/AUX 检查和五轮同包
性能对照见[常驻几何现场](../archive/block-retained-20261007.md)。多帧 pipeline 与车间 GPU
光照不属于此轮范围；温控、画面舍入和私有资产验证边界随现场记录。

本轮建立 API 1、廉价快照/按需查询、算法实例和参数 schema、明确互斥动作；
交付机械 M0 的进攻/持续防守，接通终端、CLI 对打及日志。验证记录见
[框架与机械算法现场](../archive/ai-framework-m0-20261007.md)。

后续先建立算法专用训练与独立评测，再增加候选评分、局部联合搜索和更强算法；
不要把掩护、集火、角色分组固定为框架职责，也不要把算法复杂度直接当成强度。
当前 M0 默认参数未训练，旧 utility 训练器不自动适用于新接口。

统一 Game 的原生接入范围见[此前验证](../archive/tactical-game-authority-20261007.md)。
动态语言、DSL/VM、热加载、多层策略与联机实验仍延期。
