# 枪战 AI 框架与策略搜索基础

> 状态：活动
> 所有者：Rasterfall 战术 AI
> 决策日期：2026-10-07

按用户提供的《ai策略系统计划.md》建设新战术体系。本轮先稳定共享战士/枪械、
无图形权威对局、种子地图、只读信息层、进攻/防守命令、基础策略及初步训练。
已实现合同由[架构](../architecture/tactical-ai.md)负责，执行方式由
[指南](../guides/tactical-lab.md)负责，初版训练与验证证据见
[归档记录](../archive/tactical-foundation-20261007.md)。
用户随后要求提交初版并继续完善、引入 Beam；联合动作搜索、受限预测、预算计费、
不确定终局处理与重复种子对照已实现，见[Beam 原生记录](../archive/tactical-beam-20261007.md)。

## 当前顺序

1. 将当前成员维度的联合动作 Beam 扩展为连续未来决策轮搜索。先定义引擎持有的未来
   状态句柄、未来只读候选及有界准备/推进费用；策略继续不取得 world/map 或未来 RNG。
2. 改进进攻推进与火力配合、窄 Beam 的剪枝和成员顺序偏差，重点复核五人小队。
   校准低血量、探头目标的均值死亡偏差；不确定性标记只取消硬终局奖励，尚未修复健康分布。
   参数选择仅用开发集；冻结后再用新地图、重复射击种子、交换岗位和枪种与现有训练策略比较。
3. 增加正式 Runtime Map / Game actor 的投影与执行适配，再接入 RTS 命令和图形展示。

初版不自动改写正式感染者关卡的数值。正式移植必须明确共享基准适用范围，
分别验证正式碰撞、命令优先级、session、网络和视觉链路。

## 暂缓

用户明确降低动态算法文件和语义定义的优先级：等待主体框架成熟再设计。
本轮不建设 `.rfai` DSL、VM、任意 DLL、热加载或策略语言。
对手响应搜索、神经评价与通用多层程序地图在多轮预测合同稳定后再安排。
