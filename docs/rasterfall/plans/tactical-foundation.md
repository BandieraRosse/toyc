# 枪战 AI 框架与正式 actor 统一

> 状态：活动
> 所有者：Rasterfall 战术 AI
> 决策日期：2026-10-07

用户审查后要求靶场、策略对抗场、CLI 和预测统一使用正式 Game actor。
本轮执行优先级替代此前“先扩展 Beam、后接入正式角色”的顺序。
当前所有权由[战术架构](../architecture/tactical-ai.md)维护，入口和参数见
[实验指南](../guides/tactical-lab.md)。

## 本轮交付门槛

- Game 唯一拥有身体、武器与伤害，策略只提交意图；靶场玩家正常开火。
- 实验参战者使用真实 actor 身份、正式角色表现、地图碰撞与事件统计。
- 无图形执行和游戏内分阶段执行在同一场景初值下状态一致，预测隔离主世界和 RNG。
- 原生构建、逻辑回归、生命周期、真实遮挡和统计验证；实机交互结果单独报告。
- 退役旧武器/伤害推进与旧训练参数入口，规则版本升级，文档与报告消费端同步。

## 后续顺序

本轮实现和限定原生验证已完成，范围与未签收项见
[统一 Game 验证记录](../archive/tactical-game-authority-20261007.md)。

1. 在统一 Game 规则下重新训练和评测 utility / Beam，交换岗位、人数与种子。
2. 优化观察和预测准备成本，完善短期预测的统计采样及实际导航路径风险估算。
3. 明确未来状态句柄和准备预算，再扩展多轮决策、对手响应与多层候选。

动态算法文件、DSL/VM、热加载仍延期；不在本轮增加联机实验拓扑。
旧独立模型的证据见[基础记录](../archive/tactical-foundation-20261007.md)和
[Beam 记录](../archive/tactical-beam-20261007.md)，不作为统一 Game 版本的数值依据。
