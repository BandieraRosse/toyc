## 当前状态

当前没有活动计划。2026-10-03 授权的战斗原型 V0 已完成核心、回避叠加动作及共享身体改善，详见[交付与验收记录](../archive/combat-v0-20261003.md)。

[独立 GPU 光照与天空升级](../plans/gpu-lighting.md)暂停接续，已有成果和未完成事项保留：在已有实时光照之上推进独立 GPU 天空、大气和体积云；CPU 保留静态烘焙与旧天空。用户于 2026-10-02 授权按天空设计研究继续实现。
暂停前执行优先级为实验园区与新天空组合场景的正常帧性能，初步目标稳定 60 FPS；天空观感为次要目标。
已加入保留背景的正式测试与全景巡检、调整路侧性能终端，并完成通用显示几何复用。
新巡检的平均帧耗时改善，但计算机区域和全展示长尾仍未达到稳定 60 FPS，见[本轮现场](../archive/panorama-performance-20261003.md)。
通用 GPU 常驻显示几何、相同输入准备复用和静态快照缓存已实现；本轮按用户要求收尾提交，
剩余测量、进一步增量化与长尾定位统一记录在该暂停计划的 Scene 准备优化接续中。
多帧 pipeline 延期；稳定 60 FPS 尚待完整复核。

原[角色体系与 GPU 接入](../plans/private-anime-character-gpu.md)暂停新增范围，已有成果保留。历史计划中的未完成清单不自动成为当前待办。
