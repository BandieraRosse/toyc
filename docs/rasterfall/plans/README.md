首轮可运行实现、限定路线验收与实机截图已形成，见[UI V2 原生记录](../archive/2026-10-04-player-ui-v2-native.md)。

2026-10-04 用户追加通用渲染性能优化与入图主要 GPU 资源预热；多视图复用、动作求值、调度及验证仍归该计划。
以下为此前工作的背景记录，原光照计划的剩余工作暂不自动继续。

2026-10-04 用户授权的 **网格编织机与视觉提升** 已完成本轮实现与限定范围验收：
四柱八头制造、真实枪械成本、暂停恢复、拾取使用，以及材质、阴影和天空改善。
时间中断、原生证据、性能长尾与未验证边界见[实施现场](../archive/mesh-weaver-20261004.md)。
后续仍归下述唯一活动计划，按用户实机反馈安排；历史未完成项不自动恢复为本轮待办。

2026-10-03 用户进一步授权自然肩托瞄准、真实枪械尺寸与模型适配层。本轮已接入共享 rifle pose、
物理尺寸 adapter 与 RF-C01 V28 手臂比例修订，通过方向/动作约束、CPU/Scene 冻结回归和原生近景检查；
范围与证据见[肩托瞄准与尺度修订](../archive/rifle-aim-adapter-20261003.md)。仍归下面唯一活动计划，
不扩展为全套商业动作包、逐指接触或通用自碰撞系统。

2026-10-03 用户继续授权 **角色材质与贴图、RF-C01 头脸定型、持枪动态和可换蒙皮衣裤**。
本轮以 RF-C01 与一套重装 Humanoid 为样板，特别核对手掌朝向、枪手握点、枪托贴肩及连续动作绑定。
相关执行范围已加入下面的唯一活动计划，贴图和这些动作不再属于延期项；
完整角色包、运行时表情及未列出的高级材质能力仍不自动恢复。

本轮实现与技术验证已完成：RF-C01 V26f 的五台位动作对照、角色基础色表面、完整握点绑定及
Heavy 可换蒙皮衣裤均已接通，完整 GPU 回归通过 7098 checks；验收范围与收尾证据见
[角色表面与握持现场](../archive/character-surfaces-grip-20261003.md)。

用户后续实机反馈的眼白遮挡及折腕已另行修正：RF-C01 更新为 V27 单表面眼球，双手握持加入
指节与腕部约束检查；实现及定向验证见[眼部与握持修正](../archive/character-eyes-grip-20261003.md)。

2026-10-03 后续用户授权将当前视觉工作重点转向 **RF-C01 头脸、发型和肩部、Humanoid 精修、
可组装衣服与装备外轮廓**，并行推进，仍归下面唯一活动计划管理。装备按独立厚壳、头部附件与
随腿大腿外层实现，固定实验台展示组合；不自动恢复完整角色包、贴图和全部动作计划。
该轮实现与技术验证已完成，见[角色及装备精修现场](../archive/character-equipment-upgrade-20261003.md)。

此前活动计划为[独立 GPU 光照与天空升级](../plans/gpu-lighting.md)。2026-10-03 用户授权同时推进四个方向：
修复天空转头跳变并沿既有前哨站参考改善气氛；在性能预算内改善亮暗层次、阴影与太阳展示；
实现不依赖 GPU 厂商的通用渲染优化；在整体光照下改善 RF-C01 动漫角色身体，头部仅作可选探索。
允许增加环境实验区域与适量建筑；CPU 保留静态烘焙和旧天空。

天空采样/太阳合成、实时光照、静态气氛观测区、通用包围盒与动态顶点打包、RF-C01 身体修订已实现，
完成 Windows native 构建、两厂商 GPU 行为回归、固定图检、像素对照及三轮性能采样，
详见[本轮现场](../archive/visual-upgrade-20261003.md)。无效提交减少，但长尾仍有波动，
稳定 60 FPS 目标尚未签收；多帧 pipeline 继续延期。后续依据实机观感与长尾定位继续迭代。

此前战斗原型 V0 已完成核心、回避叠加动作及共享身体改善，详见[交付与验收记录](../archive/combat-v0-20261003.md)。

原[角色体系与 GPU 接入](../plans/private-anime-character-gpu.md)仍暂停系统级扩展；本轮身体修订归当前视觉计划管理，
不恢复整份旧角色计划。历史计划中的未完成清单不自动成为当前待办。
