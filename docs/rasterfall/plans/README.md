## Active plan

当前唯一活动计划为[独立 GPU 光照与天空升级](gpu-lighting.md)：在已有实时光照之上优先推进独立 GPU 天空、大气和体积云；CPU 保留静态烘焙与旧天空。用户于 2026-10-02 授权按天空设计研究继续实现。
当前执行优先级为实验园区与新天空组合场景的正常帧性能，初步目标稳定 60 FPS；天空观感为次要目标。
已加入保留背景的正式测试与全景巡检、调整路侧性能终端，并完成通用显示几何复用。
新巡检的平均帧耗时改善，但计算机区域和全展示长尾仍未达到稳定 60 FPS，见[本轮现场](../archive/panorama-performance-20261003.md)。

原[角色体系与 GPU 接入](../plans/private-anime-character-gpu.md)暂停新增范围，已有成果保留。历史计划中的未完成清单不自动成为当前待办。
