# Rasterfall 计划入口

> 状态：当前

## Active plan

2026-10-05 用户追加前哨站 B1、一层和二层 GPU 布光，优先处理太阳遮挡、局部灯穿墙，
替换原路灯并绑定新灯具的插口与方向；固定设施以 spot light 为主，少用 point light。
该项纳入下述唯一活动计划；CPU 路径停止维护，不列入本轮开发和视觉签收目标。

随后用户要求先提交布光版本，再接入静态建筑硬件 Ray Query；基线已提交 `9327ee6`。
本轮只替换建筑可见性查询，保留软件 GPU 对照，核对原生像素、生命周期与交替性能采样。

硬件查询与建筑重复阴影剔除已提交。用户随后授权继续 GPU 光照成本定位与保守分块灯表：
细分 WORLD/透明/viewmodel/后处理区间，独立运行光照计数与消融，再核对同包画面和交替性能。
结果归[分块灯表现场](../archive/light-tiles-20261005.md)。用户随后明确追加遮挡优化和室内探针 GI，
并指定 DDGI 路线；范围为保守顶部缓存与 GPU 探针一次漫反射，改善天花板，核对隔层漏光及原生成本。
多帧 pipeline 不在本轮范围内。
原型及限定验证记录见[顶部缓存与 DDGI 现场](../archive/ddgi-prototype-20261006.md)。
2026-10-06 用户继续要求改善光照性能与墙角 DDGI，并修正顶灯与楼板干涉；本轮包括
嵌灯体积替换语法、楼板底面和灯具共面修复、有限探针重定位、插值查找优化及有界第二次反弹，仍归同一活动计划。
实现与限定验证见[墙角、嵌灯与楼板优化现场](../archive/ddgi-corners-ceiling-20261006.md)。
随后用户确认室内仍偏暗，并授权以接近现实室内照明的观感做初步亮度校准：分离天花板/地板
反射率、调整墙面与顶灯配光/强度，并核对上下部明暗、家具细节和原生成本。
结果见[室内亮度校准现场](../archive/indoor-lighting-calibration-20261006.md)。

2026-10-06 用户继续授权解决墙角三角形暗斑、降低光照成本并完成强度语义与物理单位定标。
本轮建立 lm/cd/lux/自发光亮度合同和曝光前读取，以几何短线段修正探针可见性，再用局部
实体缓存降低同画面的成本；原生验证及边界见[墙角与物理定标现场](../archive/photometric-lighting-20261006.md)。

2026-10-05 用户授权的唯一活动计划现为[边缘站点 01：首个正式行动地图](frontier-station-01.md)。
按新增任务书与概念图完成部署、三方战斗、设施回收与真实制造，并进行原生验证。
首图完成后在本轮剩余实际时间内改善小队 AI、寻路与性能。

用户随后追加前哨站楼层修复，要求先提交楼梯/建筑连接和顶面碰撞改进，再优化上下楼卡顿。
该顺序纳入上述唯一活动计划，本轮性能定位与验收范围归
[前哨站跨层现场](../archive/outpost-storey-performance-20261005.md)。

此前[玩家界面 V2 与 NULL 通讯](../plans/player-ui-v2.md)的实现与后续工作如下，当前执行顺序由新计划负责。
按新增开发任务书实施可扩展界面、共享命令与小地图、设备窗口、NULL 行为和真实通讯演出。
首轮可运行实现、限定路线验收与实机截图已形成，见[UI V2 原生记录](../archive/2026-10-04-player-ui-v2-native.md)。
后续在同一计划中按玩家反馈调整布局、效果与演出，并保留明确未测的范围。
2026-10-04 用户追加通用渲染性能优化与入图主要 GPU 资源预热；多视图复用、动作求值、调度及验证仍归该计划。
以下为此前工作的背景记录，原光照计划的剩余工作暂不自动继续。

2026-10-03 用户进一步授权自然肩托瞄准、真实枪械尺寸与模型适配层。本轮已接入共享 rifle pose、
