2026-10-06 fast 楼梯明暗边界和换图失败已修复，补齐限定原生运动与整图固定灯变化验证，
同机三轮对照保留已有收益；覆盖范围、容量代价与长尾见[本轮现场](../archive/fast-lighting-followup-20261006.md)。
