## Active plan（当前唯一活动计划）

[下一代统一 GPU 渲染器计划](gpu-scene-renderer.md)

当前进入阶段 4：在已成立的单人核心游玩帧上测量运行成本，推进资源复用与流水优化。
已优化敌人/程序角色的逐帧资源重建，以及正式模块化队员上传时的临时 staging 分配；
敌人提取已加入单次蒙皮/光照缓存，提交已复用连续 draw 绑定并拆分呈现与退休计时；
接下来评估剩余敌人提取/上传成本，角色继续评估不可变 bind 缓存和蒙皮提交合并。
2026-09-24 决策：阶段 3B 按核心功能门槛结束，不再以旧功能全面补齐、展示细节或完整交互矩阵阻塞阶段 4。
后续仅修复影响核心游玩、内容遮挡或稳定性的缺陷；正式性能签收和实机联机专项随后进行。
复用已验证的 Vulkan、skinning、资源缓存、动画和 swapchain 能力；旧路径只作独立对照与必要维护。
`--gpu-scene-independent-preview` 已接天空、地图/死亡透明、特效、第一人称和 HUD 的首版分层；
`--gpu-scene-play` 已提供实验性单人入口，补充共享暂停设置/结算/计分板布局、动态准星、
AI 状态与特效反馈。上述能力作为阶段 4 的功能基线，阶段推进不代表完整架构或产品 FPS 已签收。
画面以内容、遮挡和合理表现验收，不以旧整数光栅整图匹配阻塞。

计划中的当前切片、前置条件、完成门槛和下一决策点以该文档顶部为准。已完成 checkpoint、撤销实验和
单次设备测量进入 [`../archive/`](../archive/)，不得继续充当优先级来源。
