- 其余小幅性能优化按后续实测需要再立项，不继续沿用归档计划中的阶段 4/5 执行链。

下一项开发主线确定时，在本入口指定新的唯一活动计划。归档中的未完成清单只代表当时的计划，不自动成为当前待办。
