# 边缘站点 01：首个正式行动地图

> 状态：活动
> 所有者：Rasterfall 首图开发
> 决策日期：2026-10-05

本轮按用户提供的[开发任务书](../reference/frontier-station-01-task.md)与两张概念图完成首个可玩的工业站点。
原始概念输入：[布局图](../reference/frontier-station-01/frontier-station-01-layout-concept.png)、
[视角图](../reference/frontier-station-01/frontier-station-01-view-concept.png)；规则以任务书文字为准。
任务真值在 Game/session，部署、设施与通讯复用现有入口；先完成完整行动闭环，再完善环境与性能。

## 执行顺序

1. 地图稳定身份、通行几何、五人小队、前哨部署及返回入口。
2. 十二名守军、固定逻辑步周期感染者、整备、固定三方增援与肃清胜利。
3. 三设施接管、真实制造供给与领取、共享任务提示及 NULL 字幕通讯。
4. 按概念图完善工业建筑、能源设备、仓库、可读标识与路径遮挡。
5. Windows 原生逻辑回归、完整实机路线、CPU 冒烟与同场景性能采样，修复实际暴露的问题。

每个可运行节点独立提交。美术由 Astra 负责，其他实现与集成由 Sol 负责。真实工作窗口为
2026-10-05 01:03 至 09:03（北京时间）；不以 token 或估算推理时间替代实时时间。

任务的稳定计时、身份追踪、配额、接管权限、胜败与重试合同需要逻辑回归。空间通行、射击、
RTS 室内选择、制造领取及画面须经真实 Windows 路线确认；未验证的范围如实记录。
