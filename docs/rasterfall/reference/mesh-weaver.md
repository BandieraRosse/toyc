# 普通网格编织机

> 状态：当前实验合同
> 所有者：Game 制造规则、session 成品投影、共享机械表现
> 最近核对：2026-10-04

普通机位于前哨站实验园区，和 RF1 工作站及实验电源组成一个离线制造单元。
玩法所有权和有限弹药规则见[玩法架构](../architecture/gameplay.md#网格编织机制造权威)，
执行与诊断见[制造实验指南](../guides/mesh-weaver.md)。

## 机构与单位

机器为四根立柱，每柱上下各一个光学头，共八头；工作区上方开放。
固定底座、立柱、安装座和侧置终端合并为 `rf_mesh_weaver_frame.rmesh`。
托盘、转向架、光学内芯和三片开合叶瓣是独立局部原点网格，运行时仅改变其姿态。
Blender 生成器保留这些原点，不套用通用道具的落地或居中转换。

`mesh_weaver.components.json` 与生成头 `rf_mesh_weaver_layout_generated.h` 来源相同，
记录部件坐标、八头层级、铰链和孔口位置。资产以米描述；RFM2 量化比例按每个部件保存；
共享表现统一为每米 8192 局部单位，进入世界时换算为每米 512 RFU。
机械骨编号：托盘 0、转向架 1–8、内芯 9–16、叶瓣 17–40、制造物 41。
不要通过相机偏移、渲染放大或重写资产坐标补偿尺度错误。

工作包络约为一米，实际可制造范围以 `toy_mesh_weaver.h` 的旋转包围盒检查为准。
产品长轴按统一制造朝向放置，不针对单个武器缩小。机器是独立碰撞实体，
底座与四柱粗碰撞由地图声明，光束和制造网格没有临时碰撞。

## 蓝图测量

`tools/mesh_weaver_blueprints.py` 从完整源模型和运行资产生成
`assets/manufacturing/blueprints.json` 与 `rf_weaver_blueprints_generated.h`。
目录包括来源哈希、运行网格哈希、物理适配签名、单位换算、拓扑计数、体积及拒绝原因。
来源模型、运行网格或物理适配变化都使测量缓存失效；相机 LOD 和最终显示大小不参与成本。

制造顶点数使用焊接位置后的拓扑顶点数，导出属性拆分顶点数另列审计。
三角面取完整制造网格。体积按连通闭合壳的有向四面体和计算，方向检查后取各壳绝对值之和；
局部反向面只在测量副本修复，不更改武器资产。相交壳体的重叠部分可能重复计入，
这属于当前公开的保守实体估计，不能标注为布尔并集体积。
开放或退化实体不得以零体积进入制造；不可用蓝图仍在控制台显示原因。
当前有来源验证的 AK、手枪、SMG 和霰弹枪可制造，AWP 的开放表面和包络限制阻止开始任务。

`texture_bytes` 表示实际纹理数据规模。旧资产中指向缺失纹理的槽位不是已存在的纹理，
此类武器按其真实常量材质呈现；不能编造贴图工作量。

## 只读表现

Runtime 从 `toy_game.weaver` 冻结 `rf_mesh_weaver_frame`，共享
`rf_mesh_weaver_presentation.c` 负责完整网格解码、稳定成型次序和机械姿态。
CPU 与 GPU 分别消费同一帧值和同一姿态，渲染不推进制造、不生成产物、不扣除资源。
实际任务时间在暂停时停止，光头和成型位置保持；供给恢复继续同一任务。

成型次序沿武器规范长轴，面中心阈值和来源索引形成稳定排序。
已完成三角面使用实体材质，活跃区域使用窄带面、真实边和顶点，未完成区域保留稀疏边线。
每个光头从静态分区轨迹取真实面的重心坐标，亮束时只在该三角面内扫描；
跨面先熄束，再平滑转向，避免在不相连零件之间亮着插值。静态 BVH 检查孔口至目标间
已显形网格的遮挡，每束有固定查询预算，超出预算也熄束。
扫描使用十六个稳定区间和八头错相；默认 RF1/X1/25 kW 供给下，真实 1 ms 全流程采样
约束 yaw、pitch 各不超过 180°/s。该上限覆盖校准与交付；修改全局制造能力后须重验。
孔口和光学轴从同一内芯变换求得，任务阶段驱动叶瓣展开、形成和交付。
完成时枪械实际最低点落到量化后的承托平面，托盘与枪同步沿导轨向前交付。

GPU 缓存固定组件、武器实体及边线，仅更新刚性姿态 palette、小规模光束几何和绘制窗口。
常规帧不回传完整枪网格、不按进度重新加载资产；资源随 Scene owner 释放。
CPU 保留共享姿态的简化展示。待取阶段仍由制造表现绘制唯一枪体，
普通 pickup 绘制跳过匹配的成品槽位，session 的身份、朝向距离判定和提示保留。

当前不扩展成通用生产线、电网或跨退出存档。未来接入多机和网络时，
需先扩展 Game 实例身份、主机命令、快照与资源分配合同，不能复制当前单机终端状态。
