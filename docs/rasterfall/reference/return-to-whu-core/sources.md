## 使用规则

HIGH 只授予官方或工程文件直接给出的属性，不自动传递给同建筑的坐标、footprint 或入口标高。MEDIUM 要求独立交叉验证或误差可控的测量推导。本版没有现场几何尺寸或高程达到 MEDIUM。LOW 为单一志愿地图轮廓、方向记录及其派生测量。UNVERIFIED 表示没有依据，不是 LOW 数值；JSON 用 `null`，不能用 0 替代。

来源日期是资料自身的日期或 OSM 对象最后编辑日期，不能当作航拍日期或现场测量日期。网上存在不等于现状没有变化。所有外部资料均于调查日期获取/查看，下载原件只放 `/tmp`，未提交官方图片、卫星截图或商业地图截图。

## 坐标与复算

测量使用 pyproj 3.8.0：WGS84 `always_xy=True` → EPSG:32650。武汉在UTM 50N范围，米制输出。原点子午线收敛角约−1.3446°，直接把UTM grid north叫真实north会带旋转误差，因此本地坐标另旋转到原点真东/真北：

```text
(E0,N0) = UTM50(lon0,lat0)
(dE,dN) = UTM50(lon,lat) - (E0,N0)
gamma = meridian_convergence(origin)
X = cos(gamma)*dE + sin(gamma)*dN
Z = -sin(gamma)*dE + cos(gamma)*dN
Y = H - H_A18
RFU = meters * 512
path_length = sum(hypot(X[i+1]-X[i], Z[i+1]-Z[i]))
grade_percent = (Y_end-Y_start) / path_length * 100
```

本地投影距离不是测绘改正后的地面距离。保留三位坐标小数、两位中心线计算长度仅为了复算；图上使用取整米数，不声明其精度。未有误差依据，不能自行标成±2m或±5m。SVG平面统一2.55像素/m，PNG由同一SVG用CairoSVG 2.9.1导出，非另画缩放图；北向上、X右、Z上。比例尺0/25/50/100m相对于派生投影成立，不证明底图现场正确。

本版没有采纳GCJ-02或BD-09坐标，无跨坐标系叠加。未来高德/腾讯/百度资料必须登记原始坐标系统、转换实现及残差；不能把显示的经纬度直接填入此JSON。未知照片/图纸若缺控制点，只做形态观察。工程图若是地方独立坐标或CGCS2000，必须取得转换参数，不能默认WGS84。

## 高程取证路线与版权边界

S8明确为DSM，含建筑及植被，主要采集早于新宿舍建设；30m网格不足以确定入口、路缘和台阶标高。本次未采样，故没有“DEM得出的道路高差”。即使以后获取，也只能作为LOW的大尺度地形线索，须记录产品、采集时间、插值、地表干扰及垂直基准，不升级成道路anchor。

优先申请/寻找S6许可证对应的总平和竖向设计、S5项目竣工总平及室外道路排水图；设计单位为中南建筑设计院股份有限公司。未登录私人账号、未购买招标文件、未取得非公开图纸。无授权的官方图纸和照片只留链接及事实性测量；原图下载只留本地临时目录。
