## 仍是估算或未知的内容

全部平面几何与距离目前是LOW：使用同一WGS84 OSM矢量投影至UTM50N并旋转为本地真东/真北，计算可复现，但未取得现场控制点。17舍和18舍东西/南北外接范围各约70×24 m，图书馆约91×37 m；广场约98×74 m；操场围栏/场地约106×182 m。这些是**地图轮廓外接范围**，不是工程轴线净尺寸、广场净铺装尺寸或跑道认证尺寸。[OSM数据](https://api.openstreetmap.org/api/0.6/map?bbox=114.352,30.529,114.357,30.533)

主要入口之间的水平直线约117 m（18舍—17舍）、71 m（18舍—图书馆西门）；这些不等于步行路线。OSM未提供本区实测道路宽度，本版不由车道数制造宽度。17舍OSM层数18与工程17冲突；两舍OSM轮廓面积合计约3018 m²，比招标基底大约13%，没有强制缩放解决。[OSM17舍](https://www.openstreetmap.org/way/990913729)、[OSM18舍](https://www.openstreetmap.org/way/953298307)、[工程公告](https://www.hubeibidding.com/view/8098.html)

本版没有MEDIUM现场几何/高程测量。图书馆建筑高度、道路净宽、广场高程、入口高差、操场与路面的高差、所有连续道路总体上/下坡及分段grade均为UNVERIFIED。少数橙色箭头只表达OSM台阶incline方向，**不是已经测得的道路坡度**。[局部台阶记录示例](https://www.openstreetmap.org/way/1036845862)

Copernicus官方明确其产品是含建筑和植被的DSM，30m级不适用于直接恢复道路精确标高；本次只检查数据说明，没有下载/采样栅格，不存在DEM测得高差。[产品说明](https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM)

## 最大的三个信息缺口

1. **竖向骨架**：缺18舍—广场—17舍—图书馆前道路—操场的闭合高程链、道路变坡点和可靠高差。因此不能给3–5%范围，更不能给4.37%之类数字。
2. **建筑与场地边缘精度**：缺新宿舍竣工总平、逐栋轴线长宽、阳台/屋檐口径、广场硬质铺装边界；OSM面积与招标基底差约13%必须解决。
3. **道路净宽与运动场细部尺度**：缺车行道/人行带实测宽度、入口瓶颈、操场跑道内外边线与其北侧出入口连接；场地围栏不能替代跑道。

## 是否足够开始白盒

**只足够开始可撤回的平面布局/体量研究，不足以开始并签收真实地形白盒。**可以按源轮廓讨论四个landmark的相对位置；不能把未知地面全部设为0并称其为现实地形，也不能将图书馆高度或路宽用一般校园经验补齐。下一阶段仍须先解决高程、宽度与轮廓口径再制作正式地形骨架。本任务未生成.map。

## 下一步最值得补充的资料

优先寻求规划许可证对应总平及竖向图、17/18舍室外工程竣工图、道路排水标高与操场改造总平。工程设计单位中南建筑设计院股份有限公司、具体许可与竣工编号已经在台账定位；**没有向任何单位发送请求，也未获得非公开资料**。

如网络公开资料不足，最有效的实地包是：

- 18舍原点入口门牌、地面与相邻路口的连续照片；17舍与图书馆西/南门同样记录，照片附拍摄点、朝向、日期。
- 沿A18→广场→17舍→图书馆前道路→操场北缘/场面→返回A18做水准或其他有误差说明的闭合测量，记录每个路口、台阶上下端和变坡点。
- 用卷尺/激光分别量主要道路车行净宽、人行带、广场净边、入口台阶数与踏步高度；附测量点照片和工具精度。
- 有许可与采集日期的近期正射/无人机影像及至少三个非共线控制点；若只有商业卫星地图，保留链接与派生测量，先明确坐标系统与许可，不提交截图。
