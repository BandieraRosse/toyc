# 《重返武汉大学》— 信息学部核心区 V0 计划

> 文档更新：2026-09-13
> 源码核对基线：只读核对维护者总索引、map-format及现有地图/布局工具的RFU契约；本阶段未改变任何运行时或正式地图。

## 项目目标与本阶段状态

建立可追溯的真实地点事实层，让未来白盒能够按真实比例组织建筑、道路和地形。当前交付为[参考图 SVG](whu-info-core-reference.svg)、[PNG](whu-info-core-reference.png)、[机器数据](whu-info-core-reference.json)与[来源台账](sources.md)。它已能支持平面布局讨论，**尚不足以冻结真实地形白盒**：道路宽度、相对高程、坡度与footprint现场精度仍未核实。不要把未填高程理解为平地。

## V0 核心范围

只覆盖信息学部17舍、18舍、18舍西侧/楼前广场、东侧信息科学分馆、南侧操场及连接它们的主要道路。派生图中18舍在17舍东北，图书馆在18舍东南，操场在图书馆南侧。建筑编号必须与2021后新宿舍对应，图书馆必须用2016重建馆。

建议调查边界为本地X=−160…180、Z=−305…65 m，约340×370 m。这是包住核心对象的矩形调查范围，不是地籍线、现成关卡边界或完整信息学部。矩形内的次要道路暂作为上下文保留；未调查的周边建筑不得由空白图误读为无建筑。正式可玩边界待事实层核实后再定。

## 坐标与尺度契约

来源水平统一WGS84，测量投影EPSG:32650；另按原点子午线收敛角旋转至真东/真北。输出X=east、Z=north、Y=up，单位m，1m=512 RFU。本地平面原点为18舍南入口OSM node13227634459，固定WGS84经纬度114.3545898 / 30.5316527，Y=0只是相对高程约定。

现场需拍该入口、门牌与邻接道路来验证点身份；如点身份不成立，发布V1并显式重新配准所有几何，不能只挪某一栋楼。地理坐标小数不是真实性精度，绝不为了整齐或适应旧地图范围整体缩放。现有场景y=−900等局部实现约定不作为本关卡现实地面零点依据。

GCJ-02、BD-09及未知图像坐标不得混叠。未来输入的转换、控制点和残差写入台账；没有投影/比例尺的图只能观察形态。JSON中的未知数是null，不是0；高度范围只有在具备证据时才增加。

## 真实性原则

Reality Layer拥有真实地形、道路、建筑footprint、相对位置、主要尺寸及真实的台阶/挡墙。Gameplay Overlay拥有Rasterfall barrier、crate、敌人入口、临时设备、任务对象与任务布置。优先保持Reality Layer；不得为射界、AI或节奏随意移楼、拉宽道路、削坡、扩大广场或把真实台阶画成便利坡道。

采用属性级confidence：工程高度HIGH不使同楼OSM几何也HIGH；计算精确不使输入可靠。出现冲突先登记，禁止用终端视觉偏移或统一缩放掩盖上游错误。V0两舍OSM面积合计比招标基底大约13%，需明确不同边界口径再决策。

## 地形骨架与取证点

使用38个候选anchor，包括A18原点、A17入口、图书馆西门ALW/南门ALS、馆前道路ARL、广场APW/APE、操场北缘ATN/场面ATF与道路连接点J系列。平面来源/具体坐标见JSON。候选点并不等于已测高程点；除人为A18零外，Y全部未知。

现有局部OSM台阶上行记录提示场地存在竖向转换，但不能据此判断“图书馆一定比宿舍低”或“整条路南高北低”。先补齐入口—广场—道路—操场闭合高程链，再决定分层平台、真实坡道、台阶、挡墙与道路纵断面。每个坡段沿道路中心线算水平长度，不能用两端直线替代弯曲路线，也不能把台阶的高差/投影长度当车辆道路坡度。

官方竖向/竣工点高程最佳；否则实地水准测量、可信测量控制点或有比例依据的阶数/踏步高记录。手机气压/GNSS高度只能附方法和误差，不能自动升级。30m级DEM仅辅助大尺度趋势，不供道路精确标高；本版没有DEM样本。

## 道路系统

北侧求是大道联系广场和18舍；星湖一路穿过广场与18舍之间，向南接内部路；星湖二路在宿舍/广场西侧；求是二路沿图书馆及操场西侧，求是一路沿东侧，毕昇路处于图书馆与操场之间。上述为同一OSM数据内的布局解释，均须现状确认。

保存中心线原始折点与共享节点连通，不凭线条视觉交叉添加路口。JSON的道路分段在已识别的道路共享节点断开，未来在变坡点、平台接缝、台阶端点和转弯处分段补充。次要步道、桥和台阶有独立kind/layer；桥面路线不能自动和地面连通。道路宽度全为UNVERIFIED，不由lanes臆推；现场分别量车行道、人行/绿化带、路缘及入口瓶颈，不能混成一个总宽。

## 下一阶段第一批内容与暂缓细节

**补充资料并通过事实验收后**，先制作独立实验白盒：现实地面与道路高程骨架、主要中心线与实测宽度、广场平台、操场水平面、三栋楼外部轮廓和高度、真实出入口与可验证台阶/挡墙。每项保留引用源与confidence，实验修改不反向覆盖现实参考JSON。

暂不做建筑内部、窗户/阳台精细结构、新资产建模、精细树木/家具、全信息学部、商业店铺陈设或建筑材料还原。不在本阶段创建正式.map、spawn、AI、敌人配置、renderer改动或玩法；参考图也不是游戏碰撞真值。

## Rasterfall 玩法覆盖层

未来使用独立设计图或对象清单研究任务路径、临时barrier、crate、敌人入口、设备与任务对象。它们应摆在已验证的真实可用空间，不改变建筑底盘或真实地形。具体spawn和AI等配置等白盒空间验证后另做。本文件没有预设出生点、战斗路线或敌人波次。

渲染可见外壳、真实路面与游戏碰撞分别表达，不能用可见几何替代玩法碰撞；运行时接入依照map-format已有所有权边界另行评审。本阶段仅确定尺度契约，不新增地图格式。

## 后续扩展边界

先沿核心区已有主路向北/西或教学区扩展，具体目的地另调查。新增区域必须与同一个原点和坐标契约配准，先补Reality Layer，不从本图空白处直接发明建筑。完整信息学部、星湖及其他学部属于后续阶段。
