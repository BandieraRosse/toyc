# RF-C01 V03 成熟动漫比例候选

> 状态：设计候选，待人工审阅；不替代 V03，不代表造型冻结
> 所有者：Rasterfall character art
> 日期：2026-09-28

本轮依据 [RF-C01 设计资料](rf-c01-design-study.md)中的两张原创概念图、V03 Blender 源与生成脚本、
真实多视图渲染，以及[角色资产合同](character-assets.md)进行形体研究。
不以任何商业角色为目标；身份仍是成年 Field Technician / Rifle Operator。
纹理、复杂材质、绑定和运行时接入不属于本轮。

## 成果与打开方式

私有成果位于 `rasterfall/private-assets/source/characters/rf_c01/style-study-v03/`。
原 `design-v01/`、`design-v02/`、`design-v03/` 仅被读取，原文件不覆盖。

| 文件 | 用途 |
| --- | --- |
| `V03.blend` | 在统一摄影棚参数下保存的原几何参照副本 |
| `A-mature.blend` | 轻度 Mature Anime 候选，建议优先审阅 |

| `compare-structure-profile.png`、`compare-structure-three-quarter.png` | 临时隐藏头发后的结构检查；保存的 Blender 文件仍显示头发 |
| `build_candidates.py` | 参数化生成独立候选及真实 Blender 渲染 |

| `source-hashes.json` | 开始研究时 V01–V03 文件 SHA-256 快照 |
| `*-metrics.json`、`camera-contract.json` | 实际求值包围盒、参数与统一相机记录 |
| `make_sheets.ps1` | 将原尺寸渲染并列，加标题，不修饰渲染内容 |

每个修改对象保留 `Basis / exact V03` 和候选 Shape Key，顶点顺序、面连接与对象变换不变。
驱动器把全部候选键连接到 **Scene → Custom Properties → `style_mix`**：
`0` 恢复 V03 几何，`1` 显示该候选。不要只手调某一眼部对象的键，以免眼球、眼睑、虹膜失配。
候选强度的中间值可作探索；检查有限坐标不等于中间值已通过穿插或表情验收。
相机列表中的 `Compare / front`、`profile`、`three-quarter`、`full` 等可直接复用。

## V03 观察与比例口径

- **头身**：实际含发高度约 1.698 m，裸头顶约 1.680 m。以控制网格 Z≈1.432 m 的下巴标志作粗测，
  裸头尺度约 0.248 m，对应约 6.8 头身；将头发也算作一头则约 6.4。
  “约七头身”是概念描述，不能混用含发与不含发的分母。这些是头颈连续底模的标志点估计，
  不是人体测量认证；目前没有整体增大头部的理由。
- **脸部纵向**：眼中心 Z=1.551 m、鼻尖控制区域约 1.517–1.518 m、唇线约 1.483 m。
  眼到鼻约 33–34 mm，鼻到唇约 34–35 mm；眉高、鼻唇段偏长与下颌接颈的窄点共同造成僵硬感。
  发际线受厚发壳与刘海遮挡，现阶段不把图上的面部“三庭”等同于可靠的网格三庭。
- **眼裂/虹膜**：V03 参数眼裂宽约 47 mm、上下开度约 16 mm（外眦倾斜会影响包围盒高度）；
  虹膜含外圈的水平直径 16 mm，约为眼裂宽的 34%。横向大眼白配小虹膜产生瞪视感。
  虹膜纵径约 17.9 mm，已受上下眼睑遮挡，因此扩大虹膜必须沿球面同步重投影，不能贴平面圆片。
- **眉眼**：眉头基准比眼中心高约 27 mm，眉弓峰值更高；宽松间距与偏圆眉弓削弱专注感。
- **鼻子**：正面鼻梁与鼻尖不够有组织，侧面又出现窄而尖的突起；前视弱不等于应该把鼻子削平。
  应保留鼻根—鼻梁—鼻尖的连续深度，降低局部尖峰并拓宽过渡。
- **下颌/面颊**：Z≈1.432 m 处头颈截面半宽只有约 21 mm，相邻上方下颌快速变宽，
  正面像收成尖口，侧面颌底又缺少独立转折。面颊需保留骨性宽度，不能用大幅削颊代替成年结构。
- **多视图**：原 3/4 图片带俯视角，容易掩盖鼻唇与颌底问题。本轮用水平正交镜头，侧面严格 90°，
  3/4 严格 45°；三候选使用相同世界位置、尺度、灯光、材质、AgX、32 samples 和随机种子。

## 两个候选的具体修改

以下为相对 V03 的参数设计值；连续衰减、细分与遮挡使最终屏幕尺寸不等同于参数乘积。
`validation.json` 另记录保存后眼孔控制边界包围盒与鼻、唇、下巴标志位置。

实测眼孔控制边界（宽×高）：V03 为 **46.9×16.5 mm**，A 为 **43.2×16.9 mm**，
B 为 **44.6×20.3 mm**。本轮 54 个原版文件哈希复核一致，A/B 各有 41 个联动修改对象。

| 区域 | A：轻度 Mature Anime | B：更明显 Anime | 目的与副作用 |
| --- | --- | --- | --- |
| 身体、装备、头壳 | 身体与装备不变，头顶不动 | 同 A | 保留约 1.70 m 成年职业轮廓；仍沿用 V02 下身体块，不能据此宣称握枪可信度已实测 |
| 眼裂 | 横宽 ×0.92，开度 ×1.02；目标约 43.2×16.3 mm | 横宽 ×0.95，开度 ×1.22；目标约 44.7×19.5 mm | A 减少大眼白；B 主要增加纵向表达，避免继续横向撑脸；B 更容易显年轻或受惊 |
| 虹膜 | 水平直径 ×1.20，约 19.2 mm；占目标眼宽约 44% | ×1.43，约 22.9 mm；占目标眼宽约 51% | 保留露出的眼白和上睑遮挡；大虹膜对视线、闭眼与表情的要求更高 |
| 眉眼 | 眉头降低 6 mm，眉弓曲率保留 65% | 眉头降低 7 mm，曲率保留 50% | 收敛专注感；眉尾重新投影到头部表面。B 太平的眉弓可能显冷淡，后续表情需保留活动余地 |
| 鼻部 | 原鼻尖局部突出项保留 72%，横向过渡 ×1.18，纵向过渡加宽 | 保留 58%，横向 ×1.24，同样保留鼻梁 | 降低尖刺与球状感；百分比指生成场的鼻尖分量，绝非整个鼻子厚度。B 在正面软光下鼻子更弱 |
| 纵向五官 | 唇线提高 4 mm，鼻区下移约 1 mm，下巴标志提高约 3 mm | 分别提高 7 mm、下移约 1.75 mm、提高约 5 mm | 缩短鼻唇段，保留成年下半脸；整体头部没有放大。B 有中面部压缩、年龄感变轻风险 |
| 颌底/面颊 | 颌颈窄区单侧增加至多约 8 mm；面颊局部缩窄系数 1.5% | 增加至多约 7 mm；局部缩窄 4.5% | 修复接颈掐窄，保留颊部体积；连续衰减不会把整个下颌加宽 16/14 mm。仍缺真正颌底和口周边流 |
| 嘴与下巴侧面 | 减少唇部突出，填平部分唇下凹陷 | 同方向，配合更高唇线 | 避免鼻、嘴、下巴彼此像独立突起；现有少量横向控制行限制唇颏沟精度 |
| 短发 silhouette | 低强度抬起后发壳下缘、错开侧后发尾、稍移开刘海 | 相同操作采用更强幅度 | 保留偏分、深青短发、露眼与不对称前束；减少整齐头盔下缘，未增加发顶体积。发根皱褶和壳片感仍在 |

两个候选沿用原有平色基础材质；没有靠新贴图、睫毛纹理或高成本 shader 隐藏形体问题。
Shape Key 是离线审阅手段，不改变 RFCHAR V1 不接收 morph target 的合同。

## 视图判断与建议

建议以 **A 为下一轮主形起点**，同时保留 B 作风格强度参照。A 的眉眼收紧、虹膜增加与较完整的
鼻梁更接近“成熟、偏现实比例的动漫角色”；全身与原版保持同一成年职业体态。
B 在正面和 45° 下更容易读出动漫眼部，但更圆的眼裂与更大的虹膜增加幼态风险，
侧面鼻唇变化也更明显。若偏好 B，优先人工比较其眉眼与鼻梁的组合，再决定是否继承整张脸。

两者仍是 V03 控制网格上的形体候选，尚未达到概念图完成度。共同遗留问题包括：
眼眶外圈体积偏鼓、鼻翼与鼻底缺少明确结构、嘴唇过于线状、颌底接颈欠清晰、发根皱褶和厚壳感。
正面柔光改善不能证明侧面已解决；去发侧面和 45° 结构图应一起审阅。
下一轮应先在选定比例上补鼻底/鼻翼、口周与颌底边流，并整理发根及大束层次，再考虑 toon shading。
本轮不冻结唯一版本，也不把静态样本推进为已完成绑定或持枪样本。

0/0.5/1 求值有限、头部三条边界、相同相机灯光及图片尺寸。几何检查不证明无穿插、不证明边流适合表情。
