# 地图与建筑一米格 V1

> 状态：当前
> 所有者：地图离线规划与前哨站建筑生成
> 事实入口：`tools/map_grid.py`、`tools/outpost_grid.py`、`tools/outpost_storeys.py`

## 平面规划

格子固定为 512×512 RFU（一平方米），世界 `(0,0)` 为格线交点。格索引向负无穷取整，
格中心为 `(ix*512+256, iz*512+256)`；不得根据 room_limit 或世界大小调整规划格尺度。
地图坐标、模型尺度与连续运动仍使用既有 RFU。

占地先将宽、深分别向上取整为正整数格，再选择格线上的左下角。中心由角点和格数推导，
奇数格允许半格中心；不是将当前位置的包围盒两端分别取整。四向旋转交换宽深，
非四向放置不进入第一版设备占地规划。建筑保留大厅、翼楼、楼梯间等矩形模块的组合，
不以整栋外接矩形覆盖十字形建筑的室外空白。

建筑模块以墙中心线为规划边界，墙面、楼板厚度、玻璃框、灯具凹槽和坡面由实体规则生成，
不要求每个顶点落格线。前哨站墙厚为 150 RFU，楼板厚仍为 154 RFU；
半格 256 RFU 大于普通 actor 半径 180 RFU 加半墙 75 RFU，避免相邻格中心差 1 RFU 被墙阻挡。
门洞净宽取整为五格，两端落格线，中心可偏半格；净高、楼层高度和踏步高度保持独立。
楼梯中间隔墙占一格，平台边界与门洞共用格线，梯段端面按实际墙厚连接。

各地板装饰分区保留独立可见面，连续支撑由十字形建筑的南北轴与东西轴矩形并集提供，
楼梯门口另有同高度接缝支撑。支撑必须位于已存在的实体楼板范围内，保留有限厚度，
不填外接矩形空角或楼梯井，不增加重复渲染面。这样完整足迹的 RTS 目标校验不会
因跨两个装饰分区而回落到地下支撑或拒绝同层目标。

## 设备组合占地

设备占地以原生 Runtime Map 展开的组件碰撞包络为依据；桌椅、桌上显示器和机柜模块
作为明确组合移动，不拉伸视觉模型或向外扩张实际碰撞盒。规划器选择同模块内不重叠的
整格占地，保留实体与外墙、隔墙的距离；分离墙线和设备占地，外围墙不当设备移动。
组合内附件保持相对位置。NULL 随工位调整后重新落在格中心；World Content 身份不改变。
普通驻守横排按成员顺序从中间成员锚点生成等距格中心，间距至少为两格：
两个半径 180 RFU 的驻守身体之间还要容纳另一个同体型身体，中心间距至少 720 RFU，向上取整为两格。
园区驻守编队整体避开主要南北接入道路，并为通行身体保留两倍半径的横向净空。
不得逐人独立吸附后留下不均匀的一格间距；这只定义初始部署，不创建动态预约或静态导航障碍。

根 object 的 `attr.grid_min_x`、`attr.grid_min_z` 为所在局部坐标系内的规划左下角，
`attr.grid_width`、`attr.grid_depth` 为正整数格数。局部原点展开后，规划角点须在世界格线上；
组合内其他 object 不重复声明占地。布局导出保存世界 `planning_bounds`，
与实际 `collision_bounds` 分开；青色轮廓为规划占地，红色为实际碰撞。
这些属性由离线工具校验，Runtime 保存扩展字段，当前 Game 不消费它们。

楼内可行走格不能由建筑占地直接阻塞：墙、实体设备、楼板支撑和身体净空决定通行。
设备顶面仍可按既有碰撞规则落脚。规划占地不替代物理碰撞、施工或动态单位预约。

## 分层诊断与导航边界

`map_grid_diagnostic.py` 读取原生检查器导出的完整 Runtime Map 碰撞，保存有限楼板底面、
坡道双端高度与厚度；同一水平格可以有多个支撑节点。格中心净空、每 64 RFU 的边采样、
八邻接角点限制形成双向几何候选图，记录组件、支撑来源、阻挡来源和跨层候选。
图像使用绿色表示格中心净空、红色表示阻挡、蓝色表示高出当前层的支撑/坡道，
深色表示没有采样支撑。

诊断不是正式导航，也不证明 Game 可达：它包含全部 authored Host 机柜候选，
不包含 session 激活的动态组、实际启用柜筛选或动态单位碰撞；部分足迹支撑、
坡道过渡、落差方向和 transactional movement 的完整规则仍由 Game 拥有。
孤立组件只能说明此采样图未连接，不能直接认定地图不可达。
JSON 记录输入 SHA256、尺寸、采样假设和限制，生成物只作派生证据，不反向维护地图。

前哨站和边缘站点正式运行时采用固定一米格和独立 X/Z 原点，同格保留跨层节点，单位仍在格间连续移动。
支撑与身体查询读取覆盖足迹的格记录，格连线同时检查地面、身体和斜线两侧格。
建筑模块占位与楼内通行分开，单位临时占格不破坏静态连通图；所有权归
[Game 网格状态](../architecture/gameplay.md#敌人共享目标导航场)。边缘站点生成与基地合同见
[首图操作](../guides/frontier-station-01.md#基地与行动目标)。其他地图继续兼容原导航，
迁移和验收进度归[活动计划](../plans/tactical-foundation.md#前哨站网格标准化)。
生成和验收操作见[地图指南](../guides/map-authoring.md#前哨站网格标准化)。
