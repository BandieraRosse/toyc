# RF-C01 头型与短发结构参考

> 状态：研究建议，供下一轮造型审阅；不是已实施设计或验收结论
> 所有者：Rasterfall character art
> 搜集日期：2026-09-29
> 对照基线：v011c；当前候选仍以 [RF-C01 设计稿](rf-c01-design-study.md)为准

本次收集 22 项参考，分为 6 / 5 / 5 / 6 四组。目的不是复制某个角色，而是分别解决裸头体积、
动漫化轮廓、三维成立性和短发分束。优先级最高的是：先理顺顶后部到枕部的长弧，再建立耳后到后颈的
收束，最后改变宽发束的截面、搭接和结束位置。不要把“后脑扁”简化成对后发整体加厚。

## 核验范围与读法

- **图检**：本次下载并实际查看原图。B1–B4 属于此类；本地 v011c 的枕部、头发、嘴部对照图也已查看。
- **正文**：已核对教学正文或制作访谈，可据此提炼结构；不等于逐帧看完视频。
- **入口**：已核对作者页面、产品说明或图像索引；完整 turntable、付费源或交互模型未逐帧审阅。
- 视角栏严格区分实际原图与页面声明。没有把动态查看器的“可旋转”写成已检查全部视角。
- 表中“用途／转译”是针对 RF-C01 的研究判断，不是作者原话，也不是从图片测得的毫米数。
- 2D 设定可能按视角调整画法；3D 修形应保留同一几何的连续转动，不逐像素硬拟合所有设定图。

原图保留在各自来源；本文维护出处和分析，不把第三方参考并入角色资产。已查看的四张公开参考图临时

## 共性规律与最值得借鉴的轮廓

以下是 A 组教学与 B1–B4 原图的综合推导；不是宣称 C/D 所有视频均已看完。

1. **头壳包络和头发包络必须分开。** 先看裸头的颅体与下颌，再看发量增加在哪里。
   B1 的后脑读得饱满，关键是后上方外鼓与后下方收束同时成立；不是发型的每一处都厚。
2. **侧面需要连续长弧，也需要下方转向。** 从 forehead 到 crown 到 occiput 是连续的大体积；
   到枕下再向上颈收进。若顶部只有高尖、后段接近直墙，加大后发仍会像高帽。
3. **后脑有横向宽度。** 只在正侧推出一个点，会在 rear-quarter 露出扁板或局部包；
   后侧必须显示后中部和侧后部构成连续的圆钝体积。正后检查两侧收向颈部的节奏。
4. **耳后是三个体积的交汇区。** 颅体、上颈和侧后发在此有前后层次。B1 的短发收束与
   B4 的耳周负形尤其有用；不要把耳朵直接贴在完整发盔边缘。
5. **宽束可以薄，但不能平。** “片状感”不等于几何厚度太小；等宽、等厚、直线延伸、
   根部到尖端曲率相同，同样会产生板片感。需要沿长度改变截面、扭转和遮挡关系。
6. **嘴部先有承载面，再有唇缘。** A6 强调口周弯曲和侧面折面。动漫化可以压低唇体幅度，
   但不能只保留一条深口缝和一圈独立高光边。

最值得借鉴的轮廓特征，按本轮优先级排列：

- **B1：后上方圆鼓 → 枕下斜收 → 后颈较窄。** 同时在 profile 和 rear-quarter 成立。
- **B3：侧后发量不只位于头顶；耳后、中后段、枕下有不同高度的轮廓变化。**
- **B4：耳前束与耳后体块分开，耳廓周围留出局部负形。** 不必整耳全露。
- **B2：大轮廓保持连贯，只有少数发尾组承担外翻和破边。** 不把每条束都做成轮廓尖刺。

## 最值得借鉴的发束组织

建议把 RF-C01 的短发视作四个视觉层级；这不是要求重建四套新部件：

| 层级 | 应承担什么 | 需要避免什么 |
| --- | --- | --- |
| 发量底体 | 覆盖头皮，建立前后深度、侧后饱满度与后颈收束 | 直接成为可见、厚重、均匀的头盔 |
| 宽主束 | 建立偏分与绕头方向，以不对称截面产生宽亮面／窄转折面 | 每束都是独立闭合叶片，根宽、腰宽、尖长全部相似 |
| 次级束 | 从主束肩部或遮挡边中途露出，形成搭接和不同结束高度 | 所有缝线从 crown 一路刻到底；每个主束机械等分 |
| 少量末端束 | 在耳后、侧下缘、后颈提供短促断口和方向变化 | 环形锯齿、等间隔长针、靠很多细丝掩盖大形问题 |

**优先改四件事：** 主束横截面做成偏心圆钝楔形；宽度峰值沿长度错开；相邻束的搭接从中段开始；
末端在不同高度、不同朝向结束。保留少量薄刃末端，不要将全部发束充气成圆管。

B3 展示了短发如何在整体圆润时仍有多层轮廓；B2 展示了几根线就能把发尾组织成组。
把这两种原则转成三维时，先让灰模表达出体积，再用明暗和少量细节强化。

## 对 v011c 的具体修改建议

本次实际查看 `occiput-comparison.png`、`hair-comparison.png` 和 `lip-comparison.png`。
可观察到：后发宽束仍呈大块叶片搭在壳体上的观感，内部曲面层级弱；可见尖端集中在下缘；
裸头顶后部仍有高拱感；口部的外唇缘与周围平面的过渡仍值得单独检查。
这些是图像判断，不是网格测量，也未完成背部截面或固定转台的诊断。

| 区域 | 下一轮具体操作 | silhouette／审阅门槛 | 依据与部件 |
| --- | --- | --- | --- |
| **头顶** | 先保持当前头部总尺度，把偏集中的高拱改为前后展开的宽缓顶弧；有需要再做略低顶的独立候选。不要先全头缩放。 | 正侧看最高处不呈局部尖峰；前 3/4 不因压顶而失去颅体；顶视不是从一点机械放射。 | A1、B1；`head`、依赖头发 |
| **forehead / crown** | 分开额骨体积、发际覆盖与刘海根部。让刘海根顺着额顶过渡向后衔接，把可见束缝的起点错开。 | 侧面额部到顶区连续；刘海不形成贴在额前的直板。偏分仍清楚，双眼仍露出。 | A5、B3、D5；`head`、`hair_base`、`hair_front` |
| **occiput** | 先检查 v011c 已增加的后向体积如何分布。把局部后凸向上和两侧铺开，保留下方收束；如需增量，只在缺少的区域增加。 | 裸头 profile 有完整后弧；rear-quarter 不是扁板或单个包；rear 的上宽下窄过渡连续。不能只看带发侧面。 | A1/A2/A4、B1；显式修订头皮接口并同步依赖 |
| **ear-back region** | 建立耳后短过渡发束，与颞侧主束、后脑主束交错。耳后上颈用宽缓斜面衔接，避免单块发片直接跨过整个耳后区域。 | 后侧看得到耳廓、发体、侧颈的前后顺序；耳后不出现大空洞，也不被垂直板片封死。 | A3、B1/B4；`head`、`hair_back` |
| **nape** | 把后颈区域整理成短、贴合、逐渐收束的下层发。让主后发遮住部分根部，发尾错开；颈部保持与枕下相接的宽缓过渡。 | 侧面从后脑鼓处向颈收进；后面不出现一条齐平硬发线或等距 V 字齿；后颈与领口之间仍留清楚空间。 | A2/A4、B1/B3；`head`、`hair_back` |
| **side hair** | 保留两侧较长的身份束；改其截面和中段转向：宽面顺头壳绕向耳后，局部薄边接近面颊，尾部再收细。左右不机械复制。 | 正面仍保留侧束长度差；侧面能看到束的弯曲与层叠，而非同宽直落的纸带。 | B3/B4；`hair_front`、`hair_back` 按既有归属 |
| **rear hair** | 保留少数主束承载整体，但不要保留四片完整叶片的封闭分区。用中途露出的次级束打断边界；宽度峰值、长度、转向和搭接深度错开。 | 纯黑剪影先读到饱满发体，再读到几个不同高度的破边；灰模转光能看到宽面向薄边转折。光靠加槽或贴图不算完成。 | B3、D1–D5；`hair_base`、`hair_back` |

### 无需猜毫米数的 silhouette 操作法

下一轮先在现有固定相机旁补充诊断视图，不更改已有相机、灯光来美化对照：

1. 固定同一头高和眼线，输出正、左右 3/4、左右 profile、左右 rear-quarter、rear、top。
   诊断可用正交相机；已有非正交审阅视图仍保留作旧版比较。
2. 每个方向同时看裸头、只加底发、全部头发三种状态。叠加头壳与发型外线，确认体积属于哪一层。
3. 在 profile 上标五个锚点：额顶转折、头顶最高点、后脑最突出区、枕下收束、上后颈。
   连起来应该是连续大弧再收进颈部，不能是尖顶接直墙，也不能只向后推出一个包。
4. 在 rear-quarter 上观察耳后到后脑的横向宽度。侧面改善而此视角变扁，说明只是单方向挤出。
5. 发束分别输出黑色剪影和无纹理灰模：剪影检查体积和破边，灰模转光检查截面和搭接。
   纯黑图无法证明宽束表面已摆脱片状感，两种证据都要看。
6. 先做“重分配顶后体积”和“改变发束组织”两类独立试样，最后组合。
   不在第一次试样同时改眼位、鼻口比例、发色和灯光，避免无法判断改进来源。

不规定通用后脑增量、束数量或固定颅宽比例。v011c 已有约 11 mm 后向修订的历史记录；
本报告不据此要求再加 11 mm。若需要数值候选，应先测当前正交投影与网格尺寸，再定义独立试样。

## 下一轮交接

建议优先打开 **A1/A2 → B1 → B3 → C3 灰模转台 → D1/D2**；口部单独配 A6。
这条顺序分别回答：骨架关系是否成立、动漫轮廓如何简化、短发怎样分层、三维搭接是否成立、如何制作。
