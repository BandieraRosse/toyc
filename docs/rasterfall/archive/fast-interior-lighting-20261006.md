> 状态：历史现场，2026-10-06
> 归档原因：保存本轮候选实现、限定设备测量与未完成签收项，不作为稳定设计合同
> 当前入口：[光照架构](../architecture/gpu-lighting.md)、[对照指南](../guides/gpu-lighting.md#低成本间接光候选对照)

## 实现与交付边界

本轮采用世界空间、建筑几何分区的方向辐照度接收缓存。BSP 分区来自实际建筑 BOX 与三角形，
两套探针继续生成灯具和自然光；几何初始化阶段一次确定接收样本的探针邻居、静态遮挡权重和天空方向掩码。
普通帧预算更新 8192 个样本，普通片元遍历分区并插值六个方向的 E/π，不再执行间接探针可见性和缺覆盖天空射线。
太阳、灯具直射、建筑遮挡和角色阴影仍走原路径，并没有取消所有片元查询。

缓存保存材质反射率、金属度和曝光之前的 /100 HDR 数据；fixture/daylight 独立，零能量是有效结果。
同位置、半径与数量的灯具改色/熄灭重用布局，完整重算探针并清除其历史，然后刷新接收缓存。
几何更新重新构建，摄像机和 RTS 剖层不参与拓扑；每个 graphics owner 独立持有资源。
reference、fast、direct_only_diag 由 `RF_GPU_INDIRECT_MODE` 启动时选择；默认 **reference**。
direct_only_diag 仅用于测量下限，不能作为画质交付。

这是一版可运行、显著降低片元成本的候选，尚未达到全部签收要求。实际大地图容量加粗至 2048 RFU（4 m），
深度/凸域投影失败的分区留空，并记录 unresolved；无覆盖只采用屋顶柱开放近似或零值。
屋顶柱仅证明向上开放，不能证明整个天空半球无邻近遮挡。复杂几何可能过度断光，不能据有限截图宣称全地图隔墙正确。
没有使用 GTAO、AO 替代光传输，也没有改变主要阴影质量、灯具数量、曝光或输出分辨率。

这是每个 graphics owner 的 GPU 可见 buffer 大小，分配为 host-visible/coherent，**不是已测出的独立显存增量**。
CPU 构建固定节点约 8 MiB、样本位置约 4 MiB，加组装输出及递归候选临时内存；旧探针/几何 buffer 仍存在。
首次初始化和字段布局变化仍全量计算可见性，昂贵工作移到加载而非消失。车间 pilot 首帧 whole-loop 约 11.70 s，
包含资产、预热与上传，不能全归因于新增缓存；未单独隔离新 GPU 初始化时间。
小封闭房间灯关闭专项含读回响应约 9.61 ms，不能当成大地图实时灯光更新峰值。
摄像机移动不重建拓扑；普通预算更新约 0.12 ms，整场景灯光/天空跳变的刷新延迟与峰值尚未完整测量。

## 正确性与视觉签收

Windows native 构建通过；NVIDIA graphics 回归 **7138 checks PASS**，光照最终 r7 全套回归通过。
Core/Synchronization validation 未发现 VUID、同步危险或 validation error。
新增封闭房间回归覆盖无天空贡献、灯照明、固定灯改色/关闭、20 RFU 薄墙、无 GI、诊断模式、
无效建筑保留、建筑清空、剖层与 resize。小房间灯具间接量约 160.254 lux，灯关闭为零。
native Interactive 回归通过实际菜单/暂停/输入/移动/窗口缩放，玩家位置从 (0,-3000) 到 (0,-4900)。

World 完整换图回归尚未通过：fast 和同包 reference 都在第 61 帧进入
`return_whu_planar_massing_v0.map` 时报告 `SCENE-WORLD-GPU normal audit failed`，无 validation error。
前两张地图建立与渲染成功，但不能宣称完整资源生命周期验收通过。
保存的原始基线 EXE 同样在第三张地图、第 61 帧失败，确认该换图失败在本轮之前已存在；
证据为 `world-baseline.stdout`/`world-baseline.stderr`，该基线复现未启用 validation。
现有架构提取有 65536 primitive 上限；当前日志未直接打印失败分支，不能未经诊断把上限当成确定原因。

静态候选已见车间二层、仰看上墙/顶灯、前哨站一层与上下楼梯：层次、灯色与天花板可读性总体接近 reference，
允许的近似表现为更平滑的局部间接光分布。完整最终对照与运动证据评价见下方最终复查记录。
灯具关闭/改色只完成可量化的封闭小场景专项；有自然光的大场景交互改灯、人物跨明暗区、
脚部接触、所有门洞/复杂三角形区域和全天空变化仍不能宣称签收。
未运行软件/AMD 路径、编译器测试或更新 bootstrap；本轮没有要求扩大到这些范围。
