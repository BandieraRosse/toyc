## 归因与后续方向

计算机有成本，但本次数据不支持将其约一万面的单机网格视为外场主要瓶颈。
中央道路移除计算机主体后，主绘制 1735→1636、阴影绘制 2614→1798，GPU 时间有所下降，
整帧收益在热状态下不稳定。电子展区也有小幅下降，应保留为后续 LOD/阴影合批候选。

中央道路默认主线程 CPU 平均约 6.94 ms，GPU P50 约 4.55 ms。图层准备墙钟约 1.93 ms，
WORLD 准备约 0.81 ms，录制约 1.12 ms；图层包含显示、投影、viewmodel 和 HUD，
此次未将其中某一项单独消融，不能全部归因给屏幕。GPU 退休等待约 4.68 ms 与 GPU 执行重叠，
不是可另行相加的 CPU 计算。串行准备、提交及等待共同限制整帧。

全展示时，中央道路动态来源准备 0.46→4.60 ms，actor 渲染准备 0.76→3.04 ms，
敌人渲染准备 0.13→2.10 ms，录制 1.12→1.99 ms；主线程实际 CPU 平均 6.94→17.21 ms。
主绘制只从 1735 增至约 1751，但阴影绘制增至约 4692–4738，GPU 也升至约 9.73 ms。
这些是同窗口各阶段均值或上述独立分位数，不解释为各阶段独占 CPU 时间。

优先调查展示角色在主镜头、阴影及 AUX 各消费域中的提前剔除、求值复用和阴影 LOD，
再细分常态图层准备与 draw 录制；不能只按主视锥删除仍需投影的模型。
计算机的远景内部件 LOD 和阴影简化可作为次级候选，本次没有修改这些渲染策略。
