# 天空、光照、通用渲染与 RF-C01 身体升级现场

> 状态：历史记录；2026-10-03 的实现与 Windows native 验证
> 当前入口：[GPU 天空](../architecture/gpu-sky.md)、[GPU 光照](../architecture/gpu-lighting.md)、[GPU 架构](../architecture/gpu-rendering-architecture.md)、[活动计划](../plans/README.md)

本轮沿用户指定的前哨站天空参考改善视觉，修复天空转头不连续，增加静态气氛观测区，并改善
实时光照、通用资源准备和私有 RF-C01 身体。概念图的摄影细节尚未完全复现，当前仍为低预算解析大气与体积云。

## 实现与范围

- 云密度在高度和天气群边界连续归零，移除高频方向积分扰动，调整云形及固定晴空构图；
  默认仍为每轴四分之一分辨率、32 步。太阳盘与柔和光晕按显示像素解析合成，受云透射率与 WORLD 遮挡。
- 阴影使用连续 16 tap tent PCF，太阳级联边缘混合；保持 1024 阴影图及三级太阳、最多两盏聚光灯。
  半球环境填充区分表面朝向，降低默认直射强度，色调映射肩部归一化减少高亮提前裁白。
  灯半径、背光面和光锥之外提前跳过无贡献计算；未引入 GI、IBL 或新全屏后处理。
- 通用局部 min/max 包围盒减少偏心模型误提交；动态显示按实际颜色/纹理格式紧凑上传。
  保持透明顺序、独立主视图/阴影视锥和蒙皮例外，不隐藏场景内容。
- `atmosphere_lab_area` 使用园区第二排第三列原预留地；仓房、气象站和瞭望塔拥有独立几何/碰撞。
  复用园区地面，南侧道路镜头为 `atmosphere-lab`，观察脚本为 `gpu_sky_study.ps1 -View atmosphere`。
- RF-C01 V23a 身体与新光照同框通过固定图检；身体三角形减少 5.8%，骨架、材质数及头部保持。
  详细源、部件隔离与动作证据见[身体修订记录](character-body-v023a-20261003.md)。

## 性能口径与限制

最终 1920×1080、默认 scale 4、物理 RTX 3050、32 次隔离天空采样：默认完整扫描 compute
P50/P95 为 **1.780/2.501 ms**；候选跳过为 1.773/2.482 ms，配对节省中位仅 0.008 ms，继续默认完整扫描。
这是天空 compute，不包含后续 HDR 合成及读回；约 1 ms 的研究目标尚未达到。
旧版本机同入口为 2.180/2.699 ms，但云种子、密度与构图已改变，不能将差值全部归为通用优化收益。

通用准备优化使用同构建交替 reference/optimized，每轮预热 120 帧、记录 240 帧，1280×720、
正常 120 FPS 上限、三轮。两组中间构建的 hash 不同，分别记录，不与最终天空数据合池：

| 采样 | 可靠减少量 | 帧时间边界 |
| --- | --- | --- |
| 四个默认视角 | 主绘制减少 1.57%～26.86%，阴影绘制减少 6.88%～12.57% | 整帧 P50 约 8.39 ms；GPU P50 中位只减少 6～17 μs，不能声称明显整帧提速 |
| 全开电子区 | 主绘制 763→592，阴影绘制中位 3833→3575 | P95 三轮中位 14.346→13.041 ms；第三轮优化侧反转为 18.641 ms，P99 为 21.914 ms |

默认计算机和光照视角的 P99 中位也未改善；全开上传字节第三轮发生反转，不能当作稳定纯打包节省。
完整逐轮值及分布见 `performance-summary.json`、`perf-preparation/` 和 `perf-all-labs/`。
结论是减少无效提交且保留像素，不是稳定 60 FPS 或各 GPU 普遍帧率提升的签收。
