## V028 原始制作方法

`build_v028.py` 从 `assembly-eyes-v027.json` 锁定的部件和骨架继续制作，
不是从空场景生成完整角色。它保留肩关节，将肩至腕的横向距离扩大 25%，
手掌、手指和相关挂点整体平移；同步修改身体中对应权重区域的顶点。
身体拓扑、UV、权重和材质保持，头、眼、口、发的源条目不变，源动作保留。
骨架 rest 确实改变，不能把它描述成骨架完全不变。

输出包括 `rig/v028.blend`、`parts/body/v028.blend`、`assembly-body-v028.json`，
以及 `build/v028/` 下的组装 BLEND、GLB、验证报告、材质角色表和导入清单。
材质角色表还依赖 `build/v027/visual-roles.json`。

原会话下一条执行记录报告 `ARM REST MIGRATION PASS`：组装顶点 39048、骨骼 49、
身体变化顶点 5908；肩至腕约 0.399 m 改为 0.49875 m。
