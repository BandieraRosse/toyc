# 单表面眼球与持枪手部修正

> 状态：历史现场；2026-10-03
> 当前入口：[保真诊断](../guides/character-fidelity.md)、[动画架构](../architecture/animation-architecture.md)、[角色资产合同](../reference/character-assets.md)

用户反馈动漫角色虹膜被眼白遮挡、持枪手腕直角下折。此前挂点位置与旋转闭合的检查不足以签收实际手型。

## 原因与实现

V26f 源 GLB 的眼白与虹膜是曲率不同的独立表面。正面平行射线探针中，6,112 个虹膜命中有
3,935 个被眼白挡在前面，最深约 1.97 mm；65536 格表示仍存在，不能归因于纯深度精度。
该采样只衡量指定两种材质的正面顺序，不是全模型穿插统计。

RF-C01 V27 将眼白、虹膜、瞳孔和小高光放到同一不透明眼球表面及 UV0 基础色图，显式移除
两个虹膜和两个高光对象。眼球形状、权重、离线表情、眼睑、头脸、头发、身体及骨架保持 V26f。
单独发布 `authoring/assembly-eyes-v027.json`，源与统一导出在 `authoring/build/v027/`，
目录切换到 `private-assets/models/rf_c01_v027.rmesh`；旧版本保留。新资源仍是 v15、五张纹理，
41,727 个导出顶点、75,348 个三角形、49 骨。渲染器未增加眼部深度偏移或关闭深度测试。

持枪修正包含双臂基准姿态、主握点掌骨朝向和支撑握点内上倾角。支撑肘的 pole 以枪下方为主，
辅以目标掌骨反方向，避免固定向外导致折腕，也避免只追求腕部对齐而使上臂横穿胸部。
扳机手的掌骨延续前臂，食指单独伸出和弯曲，其余手指包握；支撑手包住护木。
RF-C01 复用已有指节，公共 Humanoid 增加兼容的可选指节与两骨权重；夹克和外裤同步为完整 49 骨。
指节由 action composition 求值，退出持枪自动清除；CPU、Scene、装备和目录展示共用最终姿态。

## 验证证据

证据目录为 `tmp/eye-grip/`，不加入 Git。

- V27 分部件隔离、原版本哈希、保存重开、GLB contract 与统一 importer 通过；只允许 eyes 变化。
- Windows native 构建、完整 `--logic-test` 通过，实际进程退出码均为 0。
  `--gpu-scene-pose-test` 共 72 个握持样本覆盖两种身体、等价高精度坐标、
  静止、瞄准、移动射击和反冲；最大挂点单轴误差 0.838496 RFU，旋转矩阵元素误差 0.009713。
  腕部方向点积最小 0.754250，约 41°；无 reach clamp，右手未被左臂求解修改，指节弯曲、
  扳机食指区别于其他手指、退出动作复位均通过。衣物、装备、回避与 CPU/Scene 一致检查同时通过。
- 四个 RFCHAR 资源的 native runtime 检查通过，mesh、纹理和三份持枪动作与 staged 运行目录逐字节相等。
- 眼部原生正面、四分之三和侧面位于 `final/face/`；最终握持、移动射击、Humanoid 与 Heavy
  位于 `final2/`。10 组捕获共 804 帧，核对真实进程退出、每一帧 Scene 来源、零 bridge/mixed、
  仅捕获帧读回及图片哈希；原生图已目检。清单汇总为 `captures-checked.json`。

数值测试保护姿态契约；肩袖、手套与枪械接触仍通过多角度实机图检判断，不把挂点闭合当作完整美术验收。
本次不增加运行时表情、换弹动作、动态手指 IK、透明角膜或新的材质格式。
