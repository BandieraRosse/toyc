# 数值方向保护与故障定位现场

> 状态：历史（首轮专项交付，用户确认收尾）
> 日期：2026-10-09
> 归档原因：实现与验证记录；不作为当前设计依据
> 当前合同：[整数方向](../architecture/gameplay.md#整数方向数值合同)、[展示旋转](../architecture/character-presentation.md#展示方向与旋转保护)
> 操作入口：[数值异常定位](../guides/gpu-scene-fixture.md#数值异常定位)

## 交付范围

用户接受约 1% 的实用容差，未要求高精度朝向格式或网络协议重构。
共享整数方向接口保留 Q10，最后最近舍入，覆盖枪手转向、感染体实际位移、命中靶和 session
托管转向；actor command 区分方向与位移，非法 aim 保留旧方向。新 Game 玩家显式使用有效 +Z 朝向。

CPU modular、Scene body、Block 与附件合成在共享表现边界归一化水平旋转，保留合法模型缩放。
数值异常使用现有日志路由，32 个固定异常键、重复计数和自动输出上限；Scene 数值拒绝与退出
可输出已有记录。严格诊断是显式模式，默认不因正常舍入改变玩法格式。

## 证据

- Windows Native 构建、完整逻辑回归通过。数学回归覆盖密集短向量、象限、轴向、比例、零值、
  缩放切换、输入极值、输入输出复用与独立浮点参考；真实枪手、三种感染体移速和 session
  对准路径通过。异常注入验证身份、1000 次合并、32 键覆盖、非有限值、严格展示拒绝及详细
  诊断开关下的权威状态/事件/RNG 一致。
- 独立辅助枚举 1,050,624 个短向量，最大分量误差约 `0.499995275` 个 Q10 整数单位。
  一百万次归一化及展示检查的局部 CPU 微基准，默认/详细模式分别约 63/59ms，无异常记录。
  这是局部单次测量，不能据此宣称详细模式更快或证明全引擎性能。
- `--gpu-scene-pose-test` 完整通过：身体、Block、感染体、五枪、装备、衣物、冻结重放与来源隔离。
  旧 rifle-cycle 用例要求矩阵等于原始 Q10 分量除以 1024；本次改为检查单位长度、方向一致和
  重放一致，避免把旧缩放误差纳入正确结果。
- RTX 3050 Laptop GPU、1280×720 原生 grid-combat：session 在第 120 帧生成四名 SMG 枪手，
  正常移动沿东北连接道路离场并继续转向观察，完成 5400 帧，真实退出码 0；
  native audit 的 bridge/mixed 为零，详细数值诊断未记录异常。
  完成兼容性与非法输入返回检查后的最终构建，另在严格模式下完成 1200 帧，退出 0，无数值异常。
- 同一原生包、每组 120 样本，默认/详细模式的 player-fps 与 dual-view 均 `valid=1`、退出 0；
  双视图各采到 17 次 AUX 更新，没有数值异常。默认 frame p50/p95 为 8430/9364µs、
  11001/14351µs；详细模式为 8404/9863µs、10869/14005µs。单轮短样本只说明未发现明显
  固定诊断成本，不构成长期性能结论。
- Linux 辅助 freestanding Game 和 Scene native 单元编译通过。session/render 编译在未修改的
  实验生命周期和旧渲染片段遇到 `free/calloc/qsort/getenv` 声明缺口，本轮未扩展为 Linux lane
  修复；不宣称 Linux 完整构建或 present 验收通过。

日志与生成物保存在本地 `tmp/numeric-*.log`、`tmp/numeric-native/`、`tmp/numeric-native-final/`、
`tmp/numeric-ui-default/` 和 `tmp/numeric-ui-detailed/`，不进入版本控制。

## 未迁移路径审查

| 路径 | 当前判断与首轮处理 |
| --- | --- |
| 普通 camera yaw/pitch 旋转 | 从约 1024 的方向做小角度更新并再归一化，不使用原始短位移；俯仰另有固定限制。本轮保留原语义。 |
| actor/enemy 展示插值 | 正点积时才混合，正常单位输入的中间长度不接近零；最终角色旋转另有独立保护。保留现有插值格式。 |
| 小队布局方向 | 从有效 anchor 方向或长度至少 256/大于队形间距的位移更新，消费为队形位置。本轮保留阈值与布局行为。 |
| 剧情面向 | 原始目标方向先参与有界小步混合，再对约 Q10 长度归一化；不直接将短位移归一化结果写入矩阵。本轮保留混合语义，身体消费仍受保护。 |
| 特感转向、出生方向、射击 ray 等剩余写入 | 用途和边界不同，未宣称全部迁入 setter；继续保留既有逻辑/弹道回归。同类整数写法仍应在新调用或规则变化时核对输入范围，不能推断全仓库已无数值风险。 |

本轮不包含完整回放、全世界状态录制、全部方向字段封装、全仓库浮点化或更高精度网络格式。
现有网格终端手动操作、多玩家拓扑与长期拥堵也未因本轮自动场景而获得完整签收。
