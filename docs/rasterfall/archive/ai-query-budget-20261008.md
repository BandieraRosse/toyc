# AI 路线、暴露查询与预算改造

> 状态：历史
> 日期：2026-10-08
> 归档原因：本轮接口改造完成；当前合同见[策略算法框架](../architecture/tactical-ai.md#策略算法框架-api-3)。

## 本轮范围

API 2 保留廉价导航表，ROUTE 返回完整折线及一致长度，并支持假想起点。
同轮 Dijkstra frontier 可在工作中断后续算；缓存不跨决策或队伍共享。
EXPOSURE 按弧长对敌方到路径的射界分级采样，返回已检查/可见位集及续查位置。
预算按有界操作在执行前扣费，查询上限与整轮额度分开统计。

M0 算法版本升至 2，配置、CLI、终端与 benchmark 同步迁移预算。
CLI 保留配置文件预算，只有显式 --budget 才覆盖；旧算法版本拒绝加载。
正式 Game 规则版本仍为 3，暴露结果没有进入真实战斗结算。

## 边界

当前适配器仍为 64×48m 单层地图；路线只描述静态通行，不保证动态角色阻挡下到达。
暴露是冻结敌方位置、正式武器射程及单一身体高度的几何采样，未建模未来走位、火力分配和伤害。
M0 继续作为机械基线，未使用新增暴露服务选择安全路线。
本轮没有做 GPU/原生 UI 实机验收或性能对照，不据上述工作单位宣称 CPU 性能提升。
