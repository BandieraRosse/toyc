# 前哨站网格路线掉落修复现场

> 状态：历史
> 日期：2026-10-09
> 范围：空间验收前的正式移动安全；固定格导航尚未迁移

本轮继续收尾[此前网格标准化](outpost-grid-20261009.md)未完成的园区路线。
稳定规则归[RTS 权威移动](../architecture/rts-command.md#权威移动)，
当前顺序归[活动计划](../plans/tactical-foundation.md)。

## 定位与修改

旧现场只有 `stage=enemies`，实际上该标签还覆盖蒙皮批次结束和光照实验场准备。
拆分标签后，在 `tmp/outpost-grid-followup-localize/` 捕获到玩家先越出道路，再持续惯性掉落；
到 frame=5100，玩家 X/Z 已达 `(-80451,-73420)`，原目标仍为 `(-9712,-34799)`。
后续出现 WORLD 准备和敌人准备失败。因此本轮先修正式移动，不能只凭旧标签认定敌人资源错误。

- 导航线段采样检查实际支撑标志，避免将无支撑区域的缺省零高度当作零高度道路。
- RTS 玩家按规划的世界方向提交每步输入，瞄准仍独立；不按镜头前进/侧移键量化路径。
- Game 新增受支撑约束的玩家输入入口，复用原加减速、地形和单位滑行。
  实际滑行后失去支撑时恢复该步身体状态、清速度/位移余数并报告阻挡，session 取消规划后重查。
  只约束 RTS 地面输入；FPS 自由离边、既有跳跃、击飞和空中运动保留原规则。
- RTS 只读审计增加空中偏移与计时；原生到达检查要求确实落地。
- 安全停止后，玩家可能仍接触道路但中心略在边缘外。分层连接允许这种已落地起点按正式
  身体规则恢复到当前支撑层；中心重新获得该层支撑后，不得再通过新的无支撑中心。
  增加边缘恢复连接用例，并在审计保留临时路点、分层游标和速度以关联停滞位置。
- 直接请求远端道路另有部署净空问题：入口两名驻守单位分别位于 `(256,-13056)` 和
  `(768,-13056)`，玩家停于 `(512,-12800)`，同时接触两人的身体；临时路点
  `(630,-13230)` 落在其中一人的身体范围内。静态连接实际验证仍通过，不能把动态身体
  阻挡归为静态拓扑失败。三组初始横排改为两格等距，中央编队整体避开主要接入道路；
  增加编队格中心、身体/通行间距、通路净空及幂等性质回归。

最初的支撑约束曾直接要求整个足迹落在单一图元上，楼梯回归揭示它会误挡坡道接缝；
最终版本对实际正式运动结果作事务判断，保留既有部分支撑及坡道规则。
仅修方向没有消除高速转角惯性掉落；方向修复与实际运动约束分别验证，不能混为同一原因。

## 验证

最终 Windows native 完整逻辑回归通过，记录在 `tmp/outpost-grid-followup-spawns-test.log`。
稳定行为用例覆盖斜向镜头下有限一米宽平台、零高度分离平台、边缘惯性阻挡与 FPS 掉落对照。
地下室、二层、屋顶和一层正式导航/移动回归通过。之后仅增加只读空中审计并通过原生构建。

支撑事务后的中间实机证据在 `tmp/outpost-grid-followup-campus-final/`。
这一轮无掉落和 GPU 审计退出，但在道路边缘安全停止、60 秒到达超时，不能记为路线通过；
`tmp/outpost-grid-followup-nav-state/` 确认停止时已落地、速度为零，中心在道路边界外，旧路径无法恢复。
边缘恢复后的最终完整实机验收在 `tmp/outpost-grid-followup-full-final/`，report 为 passed=true、
exit_code=0、70 项记录；使用 RTX 3050 Laptop GPU 和普通窗口输入。
完成大厅四向通路、指挥桌/主终端接近点、三个实验室、两段性能道路、网格场连接和终端、
返程、B1/2F/屋顶/1F 往返及楼梯入口。每个到达点检查 X/Z、目标层和空中状态，保留截图、日志和退出码。

修正编队前，`tmp/outpost-grid-followup-direct-final/` 从出生点直接请求远端道路在 60 秒后到达超时，
停于 `(512,-12800)`、身体已落地且速度为零，原生由工具正常清理退出。
它与已通过的分段路线不同；不能将安全停止记为导航通过。
`tmp/outpost-grid-followup-search-state/` 确认实际旧格尺度为 1260 RFU、节点数为 4271，
未触及节点容量，停滞时没有活动分层搜索。近端旧路点实际验证试验仍重现停滞，
结合两侧真实身体位置确定部署净空问题；该额外验证未保留，避免无收益地增加同层查询成本。
修正部署后的 `tmp/outpost-grid-followup-spawn-direct/` report 为 passed=true、exit_code=0、
28 项记录，完成出生点直接到性能道路、下一段道路、网格场连接和终端、返回大厅及楼梯入口。
网格工具八个性质/几何回归通过，完整生产者重建后相关地图和 World Content 字节不变，
设备与出生编队检查通过。两次原生通过分别保留完整分段路线与直接长距离请求的证据。
菜单操作、玻璃翻越、密集动态单位及长期性能未在此轮签收。
本次不是固定一米格、共享分层拓扑或全单位导航切换；旧容量、格外补点与不同导航实现仍在。
