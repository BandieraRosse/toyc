# 角色表面、握持与独立蒙皮衣裤现场

> 状态：历史现场；2026-10-03
> 当前合同：[角色资产](../reference/character-assets.md)、[角色表现](../architecture/character-presentation.md)、[GPU 架构](../architecture/gpu-rendering-architecture.md)

用户批准继续角色质感、RF-C01 头脸、持枪动作和可换衣裤工作，并特别要求修正手朝向与枪手绑定。

## 实现

- RFCHAR 显式 v15/MAT1 表面：基础色图、粗糙度与金属度常量；不透明 UV0，八个纹理槽上限。
  GPU 在线性光空间生成 mip，基础色因子与纹理相乘，clamp/双线性放大/三线性缩小。
  分块网格共享纹理缓冲，稳定帧复用。旧 v14/旧武器缺失可选纹理仍按原底色显示。
- RF-C01 V26f 将脸、身体及头发材质分开，增加肤色、虹膜、发流和衣物细节；整理发根、后脑与耳边轮廓。
  创作源与生成资源保留在私有资产目录。源审阅记录与原生图分别留证，不混用 Blender 与游戏结论。
- Humanoid 保持几何、法线、骨架和权重，增加皮肤、短发、靴面及织物图；五材质顺序与职业调色不变。
  Heavy 新增独立蒙皮夹克和跨膝外裤，复用最终身体 palette，按覆盖区隐藏内部身体；六件刚性装备继续装配。
  五件重装装备加入细织物表面。图检后降低织物斜纹对比，未更改几何。
- 双手使用完整握点位置与朝向；左手求解不再使用旋腕前的旧偏移。统一模型局部单位到 RFU 的边界。
  AK 按实际网格调整到 450 RFU 长度，并校准握把、护木和手掌方向；既有私有旧角色保留兼容尺度。
  静止持枪、瞄准、移动射击和反冲使用同一动作求值链，RF 模型区扩至五个对照台位：
  静止、步行、持枪、瞄准、移动射击，均使用 V26f。

## 验证证据

- Windows native 构建；`--logic-test`、`--gpu-scene-pose-test` 通过，含衣物 palette 只读、膝部跨骨变形及覆盖区检查。
- 连续握持共 72 个采样：Humanoid、RF-C01 及同模型 65536 单位表示；最大单轴误差 1.218 RFU（约 2.4 mm），
  旋转矩阵最大分量误差 0.009744，未触发左臂可达范围夹制。
- 公开 fixture 的 v14 材质回归 11 项、v15 producer/native 边界检查 17 项通过：常量、sampler、UV、
  MAT1 损坏、缺图及失败保留旧产物。三个公开 body/衣裤 runtime 与实例隔离检查通过。
- 完整 GPU 回归通过，共 7098 checks。NVIDIA 与 AMD 另分别通过 texture-set GPU 专项：
  线性因子相乘、边缘钳制、缩小 mip、共享资源释放和无效更新保留。
- Heavy 120 帧原生展示和 RF-C01 120 帧瞄准通过，要求正常 Scene 来源、零 bridge/mixed、仅捕获帧 readback、
  实际进程退出及完整日志。Heavy 图检未见明显衣裤破洞或断腕；RF-C01 握持近景支持手贴护木。
  最终细织物版本的步行帧未见明显斜纹、衣裤破洞或异常黑面。

## 磁盘恢复后的收尾证据

上述检查在磁盘清理前已完成；用户清理了原 `tmp/` 证据目录，源码、私有创作资产和 build/stage
运行资源保持完整。旧临时日志和截图不再作为当前可打开的证据链接，清理前的采样结果保留在本节记录中。

磁盘恢复后，核心诊断与最终原生捕获统一重跑到 `tmp/character-surface-final/`：

- `checks.json`：逻辑、姿态、完整 GPU、两厂商贴图，以及 RF-C01/Humanoid/夹克/外裤 runtime 共九项均退出 0。
- `face/`：V26f 正面、四分之三面、背面各 8 帧；`aim/`、`walk-fire/` 分别为 120 帧瞄准及侧面移动射击。
- `heavy/`：重装正面、四分之三面、背面各 60 帧。全部 native 捕获退出 0，manifest、PPM 与完整日志齐全，
  检查 Scene 来源、零 bridge/mixed、指定帧 readback；最终截图已目检。
- `review.png`、`back-review.png` 为上述原生 PPM 的预览拼图。模型、纹理和动作共 40 个文件与 staged 运行目录哈希一致。

这些固定帧和近景用于正确性与局部观感，不能据单张图或日志中的限帧 FPS 宣称全园区性能提升。
纹理首次加载仍有 mip 构建与上传成本；本轮未实现跨实例纹理缓存、LOD、透明发片、布料模拟、运行时表情或完整角色包。
