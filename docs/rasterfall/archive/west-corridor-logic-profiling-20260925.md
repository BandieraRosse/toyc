## 续接：导航路径与扫描归因

本轮仅增加诊断，保留 BFS、候选路径顺序及地面/碰撞判定。新增计时与计数的包含关系见
[性能诊断指南](../guides/rendering-performance.md#game-导航与扫描分段)。可复跑入口：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/gpu_scene_old_map_perf.ps1 -Stage Corridor -Rounds 1 -OutputDirectory tmp/nav-profile-20260925
```

现场使用 Windows 原生 NVIDIA GPU；证据目录保存 exe/map SHA256、参数、真实进程退出码、
逐帧日志、CPU 采样和 `report.json`。矩阵含空走廊和 32/64 两种按钮池的 fixed/realtime，
每项 360 帧、一轮。下表另取 fixed 第 161–360 帧均值，与首轮后 200 帧口径一致；

## 查询复用与高台范围排除

续接实施两处等价查询优化：

1. 高度碰撞查询通过内部可选输出返回刚算出的地面结果，导航采样成功后直接消费；
   生命周期仅限同一次调用，没有跨位置或跨 tick 缓存。
2. 高台与当前 footprint 不相交时，提前跳过坡道接缝检查；原路径即使不相交，仍先扫描
   全部图元查找相接坡道。最终相交条件、原图元顺序和坡道连续性规则不变。

`RF_GAME_LEGACY_NAV_GROUND=1` 在最终候选中恢复两处原查询路径，供同包 A/B；
`--logic-test` 以两种按钮池各 64 敌人逐 tick 比较完整 Game 字节、随机数、导航、角色、
敌人及尚未 drain 的事件，清除诊断指针后比较。720 tick 全部一致；另覆盖正式地图图元边界、
三种半径和四种高度。该用例减少 830968 次地面查询和 1970817714 项坡道扫描，
后者包含边界探测，不能当成每个正常帧的收益。

仅查询复用的第一组对照位于 `tmp/nav-ground-reuse-ab-20260925`，
exe SHA256 为 `B8B35A3042C963D37555FF8B85C635E9F624DBD38725E1AAD39C9A9A590D68B9`。
该组包含 60 次原生运行：32/64、两种池、fixed/realtime、空场、参考/复用各三轮，第二轮反序。
64 原池 fixed 的每轮逻辑均值分别为参考 4.728/4.853/5.493 ms、复用 4.511/4.514/4.953 ms；
无 Tank 为参考 3.509/3.698/3.449 ms、复用 3.361/3.352/3.299 ms。
地面查询均值由 2833.18 降到 1704.26 次/帧，fixed 的可观察 workload 逐帧一致。
仅此项没有让所有场景的整帧均值或长尾稳定改善，因此继续处理高台检查的嵌套扫描。

动态资源同时新增可关闭的 CPU 计时，拆分输入校验、map/copy/flush/unmap 和 transfer/等待。
本设备成功更新均为直接 host-visible 写入，`staging=0`；较大成本在映射/复制段，
不是逐资源 transfer 提交。保留现有资源所有权、验证、fence、flush 和 draw 行为。
详细口径与可复跑参数见[性能诊断指南](../guides/rendering-performance.md#game-导航与扫描分段)。

支持本次机制的收益；GPU 写入和等待也会波动，不能将整帧所有差值都归因给某一个查询函数。

原生构建、完整逻辑回归及上述原生矩阵通过。满载稳定 60 FPS、消除逻辑丢时和阶段 5 门槛尚未达到。

### 帧审计扰动补测

同一最终候选另做三轮 AB/BA：原池 64、fixed、360 帧，保持 GPU 动态更新细分开关关闭，
只切换 `--frame-audit`。证据和临时驱动脚本分别位于 `tmp/logic-query-audit-cost-20260925`
及 `tmp/measure_logic_audit.ps1`，六次进程退出 0，native/零旧 producer 门禁通过，
每轮开关审计的敌人/程序角色来源数量序列一致，关闭后没有 Game profile 输出。

第 61–360 帧逻辑均值，开启审计为 2.686/2.858/2.605 ms，关闭为 2.967/3.328/2.772 ms；
whole-loop 均值分别为 30.877/30.286/29.187 ms 和 29.898/37.229/28.154 ms。
本组没有分离出可重复的正向审计开销，系统、驱动及执行路径波动仍明显，不能据此声称审计加速，
也不能从已有数字中扣掉一个固定“诊断成本”。关闭帧审计仍有 Scene 分段日志，
whole-loop 不覆盖其后的全部日志输出，因此这不是阶段 5 的低扰动五轮 FPS 验收。
