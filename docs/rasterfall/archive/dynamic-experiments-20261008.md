## 验证边界

本轮 GPU 测试使用 Windows 原生 RTX 3050，包含捕获、预热与功能审计；这些运行不能作为
重构前后的 FPS 对照。静态组首次创建仍可能因资源和光照预热出现明显停顿，未引入异步预热。
共享资产缓存允许保留，销毁保证移除活动实例及其碰撞，不要求公共资源缓存立刻释放。
RF-C01 预设限 GPU Scene，要求已安装私有资源，当前支持待机、行走和射击。
本轮未扩展联机实验，也未改变现有多帧 GPU pipeline。
