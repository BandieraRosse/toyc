# 墙角可见性与光度单位定标现场

> 状态：历史现场；当前合同以架构和指南为准
> 日期：2026-10-06
> 环境：Windows native，NVIDIA GeForce RTX 3050 Laptop GPU / AMD Radeon Graphics

用户授权解决室内剩余三角形暗斑、研究降低光照成本，并把早期视觉亮度调节推进到明确的
光度单位。稳定设计见[GPU 光照架构](../architecture/gpu-lighting.md)，操作见
[光照指南](../guides/gpu-lighting.md#物理单位检查与照度读取)。

## 结论与实现

1. 精确探针到接收点的建筑可见性消除了 B1 墙脚、二层墙顶和竖向墙角的三角形暗斑。
   只在距离矩判定遮挡时补查询仍会失败：距离矩同样会错误放行隔墙探针，混入暗辐照度。
   最终使用真实几何短线段；不抬高可见性下限，也不通过补环境亮度掩盖错误。
2. 每个插值格预存附近真实 BOX 的完整列表，查询范围包含探针最大重定位距离；遇到三角形或
   超过八个实体回退完整建筑查询。前哨站 17259 格中 16421 格可缓存，约 95.1%。五个固定
   原生镜头的缓存与完整射线输出逐像素一致，包含楼梯和研究翼的回退区域。
3. 默认不再生成、保存和过滤 8×8 距离矩。每探针从 39 个 vec4 缩为 7 个；含邻居表和实体列表
   的探针 GPU 缓冲由 10788080 B 降为 3948896 B。另保留 3352288 B 的紧凑 CPU 建筑索引，
   这部分新增内存必须计入总成本，不能只引用探针显存降幅。两者合计约 7.30 MB，旧探针为 10.79 MB。
4. 灯具 profile 用 lm，方向配光转换为 cd，表面照度用 lux，白色基础材质的自发光用 cd/m²。
   颜色先归一化光度，全部照明共用 HDR 尺度；曝光只控制显示。旧 `72` 不被回溯标注为某个物理单位。
5. 前哨站 49 盏固定灯全部参与直接光，不再被相机相关的 32 灯截断改变出光量；固定来源与
   GI 一致。总上限为 128 固定灯加 32 瞬时灯，分块掩码扩为五个 uint。两个动态 spot 阴影名额
   单独按相机距离与光强评分，固定灯表顺序不变。辅助模型预览的太阳、填充和局部灯同步迁移单位。

当前顶灯/壁灯 32000/21000 lm 是保持既有大厅观感的迁移初值，不是某款现实灯具的测量结果。
自发光仍独立于灯具流明；天空外观、真实晴天太阳强度、相机曝光参数模型、完整光谱传输和
照明规范工作平面均不在已完成定标的范围内。最多两次建筑漫反射、动态模型遮挡缺失与探针
偏移误差仍需保留边界说明。

## 数值与运行验证

证据根为 `tmp/photometric-lighting/`，不提交二进制、日志与捕获产物。

- Windows native build 和 `NativeCodex.ps1 test` 通过；逻辑回归正常退出。
- NVIDIA hardware、NVIDIA software、AMD auto 三种路径的光照回归通过，均实际加载 Khronos
  validation；无 VUID、Validation Error 或 SYNC-HAZARD。GPU 光照数值和隔板零漏光用例通过。
- `PHOTOMETRY PASS`：1000 lm 在点光和两种锥角上的球面积分保持通量；100 cd 在 1/2/4 m
  正入射产生 100/25/6.25 lux，2 m、60° 入射产生 12.5 lux；颜色归一化、反射率和曝光独立。
  半径中点的理论衰减为 87.890625 lux，白 Lambert 读回 31.8115 cd/m²，对照理论 100/π。
  100 lux 太阳和 0/100/10000 cd/m² 自发光均通过真实 half-float 读回。
- `LIGHT TILES PASS` 扩展到第 31、64、159 位，颜色/深度与完整灯表一致。
  三种探针网格相位下，局部缓存与完整可见性颜色/深度一致；封闭隔板泄漏为 0。
- 14 个生成 SPIR-V 变体通过各自 Vulkan 1.0 / 1.2 的 `spirv-val` 检查。
- `cached-visual/` 与 `reference-visual/` 的 B1、一层、二层、楼梯、研究翼五对 1280×720
  捕获差异均为 0 像素。图检确认三角形暗斑消失，楼板和门洞遮挡保留。
- 最终 `release-visual/` 再与完整射线参考比较，五视图均为 0 像素差异，记录在
  `visual-comparison.json`。最终包的 `native-sync.log` 确认实际加载 Synchronization validation，
  1080p 正常场景完成 12 帧、正常退出且无同步/验证错误；该诊断时间不计入性能表。

照度工具独立输出直接光、GI 和艺术填充；`total` 只计前两者。屏幕区域统计不代表物理面积
平均照度。标准场景的解析检查是单位定标依据，前哨站截图和任意混合表面区域不能代替该检查。

最终一层地面 ROI 为 1280×720 图中的 `[390,620,500,660)`，4400 个有效像素，结果保存于
`meter-floor-final/report.json`。直接光均值 294.36 lux，GI 均值 39.13 lux；合计范围
301.07～347.17 lux、屏幕像素均值 333.49 lux。艺术填充单列 7.64 lux，不混入上述合计。
这是所选可见地面区域的读数，不是整间房或工作台面的面积照度验收。

## 成本与实验取舍

原生计时独立于 capture、validation 和 fragment counters。1080p，一层固定视图，真实时钟，
120 帧预热、240 帧采样，三轮交替。最终结果见 `perf-release/summary.json`；旧版本与
新版本画面不同，新版本包括完整 49 灯和修正后的 GI，不能把总差异解释为某一个算法的耗时。

| 版本/模式 | GPU P50 | WORLD P50 | 整帧 P50 | 整帧 P95 |
| --- | ---: | ---: | ---: | ---: |
| 任务前旧版 | 9.615 ms | 7.347 ms | 16.467 ms | 17.694 ms |
| 修正后完整射线参考 | 16.527 ms | 13.726 ms | 23.794 ms | 24.803 ms |
| 最终局部缓存 | 10.960 ms | 8.657 ms | 17.846 ms | 18.791 ms |

表中每项为三次运行对应分位数的中位数。局部缓存相对同画面完整查询减少 5.567 ms（33.7%），
相对旧版 GPU 净增加 1.345 ms（14.0%）。第三轮最终模式 GPU P50 为 11.346 ms，有波动，
不能据本固定视图外推全地图或普通战斗帧率。
最终 EXE SHA256 为 `acdee7c38e2294e2db4b9eb7230aa679d5c05fdfe8678770a53cc0acb7392874`，
地图 SHA256 为 `741b75cc55127baf21101e814a307433806f8f6e2199245015c400064fafef70`。

第一组同版本对照 `perf-visibility/` 的 GPU P50 中位数为完整射线 16.523 ms、局部缓存
10.978 ms，减少 5.545 ms，约 33.6%。WORLD 从 13.695 ms 降到 8.672 ms。
第二组旧版/改后交替 `perf-before-after/` 为 9.545 / 10.932 ms，净增加 1.387 ms；
这是正确性与固定灯来源完整性带来的代价，不能宣称相对旧版本整帧变快或稳定 60 FPS 已签收。

另实现并测试了固定灯整格遮挡证明：同一凸实体覆盖整个接收格才跳过局部灯射线，门洞、
薄墙、不同实体分别挡住各角等情况回退。八种 GPU 几何对照通过，前哨站能缓存 33572 对
灯/格遮挡，但新增片元查表和控制流抵消收益：该实验同版本开关约 11.6 / 11.2 ms，仍慢于
未接入实验的约 10.9 ms。已移除实验代码、开关和额外缓冲；原始试验保留在
`fixed-experiment/`、`perf-fixed-visibility/`，后续不能将其当作当前功能。

下一步成本研究应优先针对片元探针插值、固定建筑表面的受光复用和正常帧调度；任何更低
分辨率或更少邻居的方案都需要重新核对墙角、薄墙和运动连续性。本轮没有通过降低光线数、
减少反弹次数或遗漏固定灯来取得缓存收益。
