## 范围

新增不依赖 Game 类型的 API 1：算法注册、独立参数 schema/版本/状态、便宜快照、共享静态导航、
有额度的按需射界/路径查询、完整小队计划及合法性校验。框架不生成战术评分或强制八候选。
新机械 M0 自行决定进攻、防守、射击、换弹与任意目标坐标；没有搜索、协同或训练强度声明。
旧四种 solver 保留作显式旧接口对照。窗口终端和 CLI 默认切换到机械 M0 双方对打。

进攻完成保留原命令类型；防守持续存在。竞技回合终止与命令完成分开，连续命令模式单独验证。
Game 新控制标志只对新策略成员关闭自动空仓换弹并限制动作互斥，普通玩家/AI/靶场规则不变。
删除已经没有消费者的全图两两射界烘焙及矩阵，当前关系按需由正式遮挡查询得到。

## 边界

尚未训练 M0，也未证明它强于旧策略。现有 utility 训练器仍属于旧接口。
查询计费是合作式工作限制，不能强制抢占失控的编译 C 回调。
当前适配器面向单层实验地图与全信息观察；多层、感知、不可信插件、复杂搜索和联机实验未交付。
本轮未新增 GPU/窗口交互签收，终端接入由原生构建和 session 回归覆盖，操作观感仍待实机反馈。
