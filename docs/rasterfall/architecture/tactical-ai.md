# 战术策略与统一 Game 实验

> 状态：当前
> 所有者：Rasterfall Game / 战术策略
> 事实入口：`lib/game_actor_ai.inc`、`lib/rf_tactical_game.inc`、`lib/rf_range_game.inc`、`src/rf_tactical_session.inc`

靶场、策略对抗场及无图形 CLI 都使用正式 `toy_game` 和 `toy_game_actor`。
运动、碰撞、武器、技能、三维命中、回避、恢复和动画语义由 Game 唯一推进。
旧独立 `rf_tw` 武器结算和 `rf_tac_step` 内的另一套身体/伤害推进已移除。
战斗规则见[共享战斗](combat.md)，操作见[实验指南](../guides/tactical-lab.md)。

## 游戏内实验地图

session 持有实验配置、回合、成员身份引用、策略输入输出和统计。
对抗场的 `world.game` 与靶场的 `range.game` 借用 session 的正式 Game；CLI 独立持有 Game。
`rf_tac_unit` 的位置、生命、回避、弹药等字段只是每步从正式 actor 刷新的只读投影；
其 action、destination 与候选路线属于策略意图，不是第二份身体执行状态。
禁止把投影复制回 actor。成员以 actor ID 与 combat generation 联合解析，不能只认槽位。

双方均创建正式 Lv2 standard actor，阵营不同，武器和技能规则相同。
角色通过正常 character ID、Scene actor source、持枪、动画和特效链展示；
渲染器不再临时构造 actor 或按实验射击计数猜测弹道。
阵亡/倒地、有限备弹和回避窗口遵守正式规则；本实验外部控制不执行普通队友救援策略。
玩家观察者仍可使用普通移动、跳跃和 FPS/RTS 视角。

普通 AI 与战术策略选择行为的方式不同，但使用共同 Game 导航、转向限制、瞄准准备、
命令、武器与动画执行设施。`controller_external` 选择有界外部意图，替代该 actor 的普通
自主决策；它不会在正常世界更新之外再推进一次角色。已接受的 RTS 移动/停止命令优先于
外部移动意图。目标更换清除瞄准准备，死亡或 generation 失效的旧目标不能继续射击。

每个运行步先收集双方只读观察并提交计划，再执行正常 session/Game 更新，最后刷新投影、
判定回合与采集统计。统一采用正式 Game 的 16ms 规则步；Windows 调度仍为 16667us。
200ms 决策边界落到下一个 Game 步，间隔交替量化，不再另设 20ms 实验累加器。
伤害顺序沿用正式 Game 的 actor 更新顺序，不保留旧模型的同时伤害结算。

实验暂停给参战 actor 设置 `simulation_paused`，冻结移动、武器和恢复，也拒绝对其造成伤害；
观察者继续移动。游戏总暂停不推进实验。终端打开不暂停对局，只屏蔽玩家射击输入。
reset/unload 在 Game 重建前释放实验成员与预测副本；重置通过正式生成和装备入口恢复角色。

## 靶场与事件统计

AI 与玩家使用分开的实际标靶；AI 标靶相对各射道中心偏移，玩家射道中心不变。
AI 提交射击节奏和目标意图；玩家的开火和换弹直接走正常 session，终端不替换其结算。
射手使用正式 player 能力模板，目标使用 Lv2 standard 模板。靶场通过正式弹药字段明确配置
无限备弹，对抗场保持正式有限备弹。`rf_tw_state` 在实验 UI 中仅是武器读数，不再推进。

半身和探头由 Game 的 `range_cover` 实体碰撞盒遮挡；Scene 从同一碰撞盒只读生成遮挡板。
AI 瞄准可见高度，玩家需实际瞄准露出的身体。命中不再由“最近标靶 + 概率矩形”决定。
CLI 的移动目标也提交正式移动意图。

`toy_game_actor_resolve_shot()` 发布有界 `shot_history`：源 ID/generation、开火序号、
时刻、源位置和各弹丸的真实命中、生命损失、回避消耗。消费者按 serial 读取，不修改事件。
靶场按真实源身份和命中目标归属统计；未中弹按射线方向归属最近射道，实际距离另存。
采集跟不上环形历史时累计并导出 `missed_events`，不能把缺样报告当完整测量。

目标每次击杀后由正式 combat reset 开始下一试次。TTK 从试次首发到击杀，未完成时长单列。
玩家打入 AI 标靶造成混合射手试次时，不将该击杀计作独立射手 TTK。
`damage`/`health_damage` 是确认生命损失，`absorbed` 是实际回避消耗，均不使用旧解析期望。

## 地图与信息层

种子生成器产出掩体与正式 Game collision primitive；信息层节点与边由
`toy_game_short_connection()` 验证，射界由正式三维遮挡查询产生。
游戏内绑定时从当前 Game 复制真实 collision primitive 并重建候选图；
实际执行始终使用当前 Game 的导航与身体碰撞。几何内容 hash 包含 primitive 的形状、范围、
高度、厚度及标志。地图几何存活期间保持不可变，换代后重建候选和预测。

当前战术候选仍针对单层 64×48m 实验区；多层正式导航已经存在，但战术候选与路径风险
尚未扩展到通用多层策略。CLI 种子场景与游戏内装饰/控制区不必具有相同几何 hash；
跨前端比较必须使用相同碰撞、规则和初始 actor 状态，不能仅凭 map seed 认定场景相同。
半身掩体提供描述性候选信息，不再虚构站位之外的探身射线。

observation 仍是按队伍生成的固定容量只读值快照，包含有效生命、关系和候选。
solver 只获取这份快照，不持有 Game/map 指针；只输出经版本、地图/成员代际、时间、目标与
候选验证的计划。候选路线只提供建议，真实角色的路线与到达时间由正式导航决定。
关系火力和路径风险是基于正式武器数据的廉价近似，不是第二个伤害模拟器或精确命中概率。

## Beam、无图形执行与版本

simple、mechanical、utility 和成员维度联合动作 Beam 保留。Beam 廉价评分消费引擎关系事实，
不再自行推进旧武器状态机。零预算返回合法 HOLD，工作预算不读取墙钟时间。
一次前缀评价、一次预测 Game 步、一次预测叶评分各计一个单位；完整时域不足则不运行截断预测。

预测服务深复制 Game，借用生命周期内不变的地图事实，并从每次独立根副本开始推进。
它调用与真实执行相同的 Game 更新；随机流由公开种子和当前规则时间另行播种，不读取真实
未来随机流，不把预测写回主 Game。当前是单分支采样，不是旧均值伤害，也不是胜率估计；
`uncertain_shots` 保守标记预测不确定，禁止把一次采样胜利升级为确定终局奖励。
默认假设对手 HOLD，根行动在时域内保持；连续未来决策轮和对手响应仍未实现。

CLI 直接链接同一 `game.c`，省略窗口/GPU。回放只读取 JSONL；训练只调策略权重。
规则/策略版本升级为 2。旧 `trained-v1.cfg` 保留为旧模型历史数据并拒绝作为当前策略加载，
游戏终端不再列出它。重新训练结果使用版本 2；旧胜率和 TTK 不可与新规则直接合并。
动态算法语言、DSL/VM 与热加载继续延期。
