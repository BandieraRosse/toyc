# 战术策略与统一 Game 实验

> 状态：当前
> 所有者：Rasterfall Game / 战术策略
> 事实入口：`include/rf_ai.h`、`lib/rf_ai.c`、`lib/rf_ai_mechanical.c`、`lib/rf_ai_normal.c`、`lib/rf_ai_tactical.inc`；`lib/game_actor_ai.inc`、`lib/rf_tactical_game.inc`、`lib/rf_range_game.inc`、`src/rf_tactical_session.inc`

靶场、策略对抗场及无图形 CLI 都使用正式 `toy_game` 和 `toy_game_actor`。
运动、碰撞、武器、技能、三维命中、回避、恢复和动画语义由 Game 唯一推进。
旧独立 `rf_tw` 武器结算和 `rf_tac_step` 内的另一套身体/伤害推进已移除。
战斗规则见[共享战斗](combat.md)，操作见[实验指南](../guides/tactical-lab.md)。

## 策略算法框架 API 3

新框架只规定问题与执行合同，不规定怎样集火、推进或防守。算法只包含 `rf_ai.h`，
不能访问 Game、战术 world 或 renderer。`rf_ai.c` 提供编译期算法注册、参数 schema、
实例初始化/重置/销毁、合作式工作预算及输出校验；`rf_ai_tactical.inc` 是 Game 适配器。
加入新算法时注册 descriptor，并补构建源文件；不必改变观察、动作协议或复用旧评分函数。
不支持不可信插件、动态语言和任意代码的强制抢占。

算法 descriptor 独立声明版本、参数名称/默认值/范围、私有状态大小和决策回调。
状态只保存策略记忆，成员身份/命令代际变化时清空。执行反馈通过下一轮 snapshot 提供。
游戏/回放规则版本为 4，包含飞行子弹与简化回避；接口版本为 3，`mechanical-v3` 算法版本为 2、`normal` 为 1，三者不能混用。
API 2 改变查询结构、backend 计费回调和预算含义；旧算法配置版本拒绝加载，不与 API 1 的预算数值直接比较。

API 3 追加来自正式 Game 的武器散布、单发伤害、弹速、距离衰减、瞄准/转向与容量上限事实。

### 低成本数据与查询

基础快照直接复制命令区域、占领进度、双方成员 ID/generation、位置/朝向、生命/回避、
弹匣/备弹、武器射程、换弹/瞄准/冷却读数、累计战斗计数、上一动作及到达/受阻/目标失效反馈。
当前实验是全信息模式，敌方也来自正式状态；这不是带战争迷雾的感知接口。
静态导航节点和边在地图准备时复制为无评分的共享只读表，只借用到本次决策返回。
机械算法不生成旧八候选、全员火力矩阵或逐段路径伤害积分；旧的无消费者全图两两射界表已删除。

`SHOT` 查询当前或假想平面位置到指定敌人的正式射界与射程；`CONNECTION` 查询直线通行。
`ROUTE` 查询任意目标点，返回包含起终点的完整折线、与折线一致的几何长度和近期路径点。
可用 hypothetical/from 指定假想起点，以中间点串联绕行；不改变成员真实位置。
直线可达时直接返回；否则使用最近可连接节点和同源 Dijkstra 树，近期点可经通行检查跳过中间节点。
不可连接的目标返回 NO；预算不足或折线超出容量返回 UNKNOWN，不发布截断路线。
路径与射界没有战术评分，不替算法挑目标。ROUTE 是静态单层图事实，不保证动态角色阻挡下到达；
实际运动由 Game 导航执行，受阻后算法可重新查询或选择别处。当前适配器范围仍为 64×48m 单层实验区。
查询区分 YES、NO、UNKNOWN，额度不足必须返回 UNKNOWN。
路线是算法持有的值，带命令/成员组合代际、地图代际、队伍、成员和规则时间；暴露查询拒绝过期路线。
同轮当前射界和同源路线树可复用，源点变化重建路径树，预算耗尽留下的 frontier 可在同轮继续扩展。
双方及不同决策调用不共享这些缓存；逻辑收费只受本次调用顺序影响，不受另一队或 CPU 热缓存影响。
没有在 snapshot 中准备精确命中概率或未来伤害。

### 路线暴露与工作计费

`EXPOSURE` 消费完整路线，按弧长均匀采样并包含起终点；sample_count 可选 2–128，
通常使用 8/32/128 做粗/中/细筛选。结果逐点提供位置、沿程距离、tested_enemies 和 visible_enemies 位集。
查询方向是敌人到路线位置，使用敌方武器射程、正式射击起点和受评成员的身体目标高度。
敌人冻结在当前快照，检验身体中心高度的几何射界，不计弹药、瞄准时间、未来走位、火力分配或期望伤害。
YES 只表示请求范围全部检查完毕，不表示安全；采样之间也不能据此保证没有暴露。
算法可以组合或自行构造同快照折线；EXPOSURE 不验证折线通行，几何可达性需用 ROUTE/CONNECTION 验证。

预算不足返回 UNKNOWN 和已完成样本前缀；最后一个样本可能只有部分敌人完成检查。
samples_completed/next_sample 与 tested_enemies 明确区分未查询和受遮挡；first_sample 可重试首个未完成样本。
续查仍对折线校验和重试样本收费，避免把部分结果当成完整安全结论。

查询与算法主动 `spend()` 共用确定性预算；max_work 为单次查询上限，0 表示使用剩余额度。
查询入口收费 1；一次通行检查或射界/敌人检查收费 2；节点扩展（最多 12 条边）、路径追溯/暴露折线校验、
暴露采样位置各收费 1；最近节点的距离扫描和树初始化每 32 个节点收费 1。所有工作在执行前扣费。
射界缓存命中只付入口费用；路径树缓存免去重复扩展，但目标连接、路径提取与平滑仍收费。
这些单位反映有界工作，不代表等 CPU 时间；单条几何查询仍受实验区碰撞容量约束。
局部限额记 limited，不自动标记整轮 exhausted；预算、节点扩展、通行/射界检查和缓存命中分别统计。
所有编译算法必须合作扣费，框架不会抢占一个恶意或失控的 C 回调。
计时只作诊断，不影响分支；数据准备、含查询的决策耗时、其中的查询耗时分别记录，
不能把 query_seconds 再加到 solver_elapsed_seconds 上。

### 输出与命令生命周期

每个存活成员输出一个互斥动作：HOLD 保持且不自动开火/换弹；MOVE 前往算法指定的任意合法平面坐标；
FIRE 对指定 ID/generation 敌人瞄准开火；RELOAD 请求正式换弹。无需候选槽编号。
新控制模式关闭自动空仓换弹，算法必须明确请求；已开始的换弹仍由 Game 完成，期间不执行策略移动。
RTS 移动覆盖策略移动，互斥模式下也屏蔽同一步开火/主动换弹。普通角色和靶场保留原自动换弹规则。
零预算返回全员明确 HOLD；非法动作按成员回退 HOLD，过期计划由宿主拒绝。Game 始终拥有最终执行权。

进攻是一次性命令：区域内无存活敌人，至少一名存活队员进入区域并持续满足原占领时长后，标记 captured；
保留 ATTACK 类型，不暗中改成防守。防守持续存在，不因敌人暂时消失而完成。
`continuous_commands` 可关闭实验胜负终止，只保留命令推进；默认竞技对局仍在占领、攻方被消灭或
超时等条件下结束。对局结束与防守命令完成是不同概念。

### 初始机械算法 M0

`easy` 是 `mechanical-v3` 的别名，保持原算法作为简单难度。它是第一份基线实现，没有搜索，也没有训练强度声明。进攻时检查有限个最近敌人，
有射界就停止移动并射击；空仓请求换弹；否则向目标区域内由算法分散选定的位置行进，使用查询返回的
近期路径点绕过障碍。进入区域内部后保持，满足占领条件即完成。
防守时返回并保持目标区域，有敌人可射击就交战；超出区域加 leash 的范围时优先返回。
不追击不可见敌人，不预设掩护组、集火分配或换弹协同。每轮按成员分配额度并轮转起始成员，
预算不足的成员保留完整 HOLD；上次有效 MOVE 可继续，受阻则重新查询。
API 2 的 M0 默认预算调整为 16384，并把剩余成员额度作为 ROUTE 的单次上限；它仍不消费暴露评分。

算法自带两个未训练参数：`reload_fraction` 和 `defense_leash_m`。它们属于 M0 schema，
不构成所有未来算法通用的参数表。`algorithms` 命令列出注册算法、算法版本和参数范围；
配置先声明 solver，再声明 algorithm_version 和参数，版本/范围/重复键均校验。
原 simple/mechanical/utility/Beam 留作旧接口对照；它们仍使用旧观察和 HOLD 自动交战语义，
不能把旧算法的耗时、预算单位和动作能力与 API 2 当作完全相同的实验条件。

### 普通难度

`normal` 是有界规则启发式，使用同样的角色能力、命令和信息，没有伤害、散布、射速或
转身加成。它从可射击敌人中选择收尾目标，按已分配火力鼓励协同并减少明显过量分配；
交战中保持目标，出现可射击目标时立即结束移动承诺，减少重复瞄准。

没有当前射界时，评估目标区、附近方向点与导航节点，按本枪距离输出、敌方射界、路径
暴露和队友间距选位。只查询有希望的路线；未完成的查询不视为安全。移动短暂保持以减少
摆动，失去敌人后继续进占；防守候选限制在目标区内。占领允许一人进入，其余成员可以留在外侧交战。
有目标时优先稳定射击，暂不实现成熟的受压撤退、交替掩护或多步搜索。

空仓立即换弹；有弹主动换弹尽量与队友错开，无直接威胁且弹匣不足一半时补弹。
三个参数为 reload_fraction、exposure_weight、objective_weight，完整范围由 `algorithms`
输出。当前参数是人工工作值，没有训练收敛保证；狭窄路线、局部评分和火力估算允许有不足。
HOLD 保持原有不自动开火/换弹合同。本轮只要求行为可区分，且同条件换边对打具有统计优势。

## 游戏内实验地图

session 持有实验配置、回合、成员身份引用、策略输入输出和统计。
对抗场的 `world.game` 与靶场的 `range.game` 借用 session 的正式 Game；CLI 独立持有 Game。
`rf_tac_unit` 的位置、生命、回避、弹药等字段只是每步从正式 actor 刷新的只读投影；
其 action、destination 与候选路线属于策略意图，不是第二份身体执行状态。
禁止把投影复制回 actor。成员以 actor ID 与 combat generation 联合解析，不能只认槽位。

双方均创建正式 Lv2 standard actor，阵营不同，武器和技能规则相同。
角色通过正常 character ID、Scene actor source、持枪、动画和特效链展示；
渲染器不再临时构造 actor 或按实验射击计数猜测弹道。
阵亡/倒地、有限备弹和简化回避遵守正式规则；本实验外部控制不执行普通队友救援策略。
玩家观察者仍可使用普通移动、跳跃和 FPS/RTS 视角。

普通 AI 与战术策略选择行为的方式不同，但使用共同 Game 导航、转向限制、瞄准准备、
命令、武器与动画执行设施。`controller_external` 选择有界外部意图，替代该 actor 的普通
自主决策；它不会在正常世界更新之外再推进一次角色。已接受的 RTS 移动/停止命令优先于
外部移动意图。目标更换清除瞄准准备，死亡或 generation 失效的旧目标不能继续射击。

每个运行步先收集双方只读观察并提交计划，再执行正常 session/Game 更新，最后刷新投影、
判定回合与采集统计。统一采用正式 Game 的 16ms 规则步；Windows 调度仍为 16667us。
200ms 决策边界落到下一个 Game 步，间隔交替量化，不再另设 20ms 实验累加器。
伤害顺序沿用正式 Game 的 actor 更新顺序，不保留旧模型的同时伤害结算。

实验暂停给参战 actor 设置 `simulation_paused`，冻结移动、武器和恢复，也拒绝对其造成伤害；
观察者继续移动。游戏总暂停不推进实验。终端打开不暂停对局，只屏蔽玩家射击输入。
reset/unload 在 Game 重建前释放实验成员与预测副本；重置通过正式生成和装备入口恢复角色。

## 靶场与事件统计

AI 与玩家使用分开的实际标靶；AI 标靶相对各射道中心偏移，玩家射道中心不变。
AI 提交射击节奏和目标意图；玩家的开火和换弹直接走正常 session，终端不替换其结算。
射手使用正式 player 能力模板，目标使用 Lv2 standard 模板。靶场通过正式弹药字段明确配置
无限备弹，对抗场保持正式有限备弹。`rf_tw_state` 在实验 UI 中仅是武器读数，不再推进。

半身和探头由 Game 的 `range_cover` 实体碰撞盒遮挡；Scene 从同一碰撞盒只读生成遮挡板。
AI 瞄准可见高度，玩家需实际瞄准露出的身体。命中不再由“最近标靶 + 概率矩形”决定。
CLI 的移动目标也提交正式移动意图。

`toy_game_actor_resolve_shot()` 发布有界 `shot_history`：源 ID/generation、开火序号、
时刻、源位置和各弹丸的真实命中、生命损失、回避消耗。消费者按 serial 读取，不修改事件。
AK / SMG 的 FIRED 只累计发射，IMPACT 累计命中与伤害，不重复计发数。假人死亡后等本侧
在途弹清空再重置，避免把同一轮的迟到弹算入下一次 TTK。
靶场按真实源身份和命中目标归属统计；未中弹按射线方向归属最近射道，实际距离另存。
采集跟不上环形历史时累计并导出 `missed_events`，不能把缺样报告当完整测量。

目标每次击杀后由正式 combat reset 开始下一试次。TTK 从试次首发到击杀，未完成时长单列。
玩家打入 AI 标靶造成混合射手试次时，不将该击杀计作独立射手 TTK。
`damage`/`health_damage` 是确认生命损失，`absorbed` 是实际回避消耗，均不使用旧解析期望。

## 地图与信息层

种子生成器产出掩体与正式 Game collision primitive；信息层节点与边由
`toy_game_short_connection()` 验证，射界由正式三维遮挡查询产生。
游戏内绑定时从当前 Game 复制真实 collision primitive 并重建候选图；
实际执行始终使用当前 Game 的导航与身体碰撞。几何内容 hash 包含 primitive 的形状、范围、
高度、厚度及标志。地图几何存活期间保持不可变，换代后重建候选和预测。

当前战术候选仍针对单层 64×48m 实验区；多层正式导航已经存在，但战术候选与路径风险
尚未扩展到通用多层策略。CLI 种子场景与游戏内装饰/控制区不必具有相同几何 hash；
跨前端比较必须使用相同碰撞、规则和初始 actor 状态，不能仅凭 map seed 认定场景相同。
半身掩体提供描述性候选信息，不再虚构站位之外的探身射线。

旧 solver 的 observation 是按队伍生成的固定容量只读值快照，包含有效生命、关系和候选。
solver 只获取这份快照，不持有 Game/map 指针；只输出经版本、地图/成员代际、时间、目标与
候选验证的计划。候选路线只提供建议，真实角色的路线与到达时间由正式导航决定。
关系火力和路径风险是基于正式武器数据的廉价近似，不是第二个伤害模拟器或精确命中概率。

## 旧接口 Beam、无图形执行与版本

simple、mechanical、utility 和成员维度联合动作 Beam 保留。Beam 廉价评分消费引擎关系事实，
不再自行推进旧武器状态机。零预算返回合法 HOLD，工作预算不读取墙钟时间。
一次前缀评价、一次预测 Game 步、一次预测叶评分各计一个单位；完整时域不足则不运行截断预测。

预测服务深复制 Game，借用生命周期内不变的地图事实，并从每次独立根副本开始推进。
它调用与真实执行相同的 Game 更新；随机流由公开种子和当前规则时间另行播种，不读取真实
未来随机流，不把预测写回主 Game。当前是单分支采样，不是旧均值伤害，也不是胜率估计；
`uncertain_shots` 保守标记预测不确定，禁止把一次采样胜利升级为确定终局奖励。
默认假设对手 HOLD，根行动在时域内保持；连续未来决策轮和对手响应仍未实现。

CLI 直接链接同一 `game.c`，省略窗口/GPU。回放只读取 JSONL；训练只调策略权重。
规则/策略版本为 4；正式 Game 的动态单位碰撞同时进入执行与隔离预测。
旧规则下生成的策略文件须按版本拒绝，不能把训练权重直接标为新版训练结果。
`trained-v1.cfg` 保留为历史数据，游戏终端不再列出它；当前内置未训练预设及训练输出使用版本 4。
旧胜率和 TTK 不可与新规则直接合并。
动态算法语言、DSL/VM 与热加载继续延期。
