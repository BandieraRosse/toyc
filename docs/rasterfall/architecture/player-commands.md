# 玩家命令与界面所有权

> 状态：当前
> 所有者：Game Runtime 命令适配；Game/session 业务真值

GUI 与终端共用 `rf_player_request → rf_player_execute → rf_player_result`。
终端 registry 仅解析参数，不复制制造、RTS 或对话规则。结果包含稳定错误码与可读文字，
UI 按请求执行时的当前世界、任务、对象和资源重新校验。

## 分层

- `rf_player_ui`：主题、尺寸描述符、布局求解和只读 HUD；不推进玩法。
- `rf_player_panels`：通用窗口、按钮、命中区域和各面板投影；绘制与命中共用布局。
- `rf_minimap`：一份地形缓存、世界/屏幕变换与可见友军/设备/目标标记；无全敌人扫描。
- `rf_player_commands`：结构化执行、只读制造查询、通知合并与界面偏好文件。
- `rf_device_commands`：渲染能力与指挥桌的查询、设置、部署校验；通过有界回调访问展示所有者。
- `rf_ui_font`：离线生成的 Sans 字形缓存与 UTF-8 排版；世界字体和实验旧界面保持原字体契约。
- `rf_story`：独立会话/队列/任务/持久化；不依赖 FPS/RTS 或窗口开关。
- `rf_player_runtime.inc`：同步输入上下文、HUD 投影和唯一辅助镜头请求；嵌入现有 runtime 编排。
- Game/session：制造进度、消耗、成品、角色生命、已有 RTS 目标及世界生命周期。

`rf_game_runtime` 持有 UI 偏好、面板交互状态和剧情服务。编织机实验兼容面板只借用当前 runtime，
也经同一命令执行。所有 renderer 回调只读；Scene 将 canvas 冻结为 GPU OVERLAY 几何。

## 请求与权限

制造与 RTS 请求携带 world generation；开始/领取同时带 job serial。
领取确认还绑定当时看到的旧武器，避免确认期间换槽后误替换；空槽 `-1` 与手枪 `0` 不以真假判断。
设备执行层核对本地存活角色、实际距离与高度、地图中的机器、离线模式、制造资源及目标状态。
查询不推进任务或补充资源。已开始/已领取请求重放安全拒绝。

普通终端为 USER 权限，显式实验模式提升为 ADMIN；开发重播/重置、旧 `killall`/`give+`/`pose`
需 ADMIN。没有 context 时不默认授予开发权限。新普通 RTS 栏不提供实验传送。
当前选择能力是本地玩家或旗帜小队；停止命令只支持本地玩家，旗帜小队保持已有集结语义。

`render/table/devices` 注册表入口共用 `rf_device_execute`。渲染窗口只调用该服务的显式设置，
不重复维护开关规则；能力查询区分正式、实验、不支持和未实现。指挥桌选择仅改变预览，部署请求
保存 world ID 与代际；主循环消费队列时复核离线、前哨站、角色与桌旁距离/高度，再走原世界重建路径。
`rf_game_request_world` 先以零初始化的独立 session 加载、验证目标 identity/content 和地图投影，再卸载该
临时 owner；预检失败保留当前世界代际、剧情和 movement hold。通过后仍由当前 session 执行正常重建，
不复制含内部自引用的 session。预检与正式加载间若发生文件变化或第二次分配失败，当前实现没有事务回滚；
调用方须呈现失败结果，不能继续报告部署成功。

## 输入与持续状态

普通通讯自动演出，不拿取移动、射击或鼠标；玩家主动展开聊天记录才取得指针焦点。
聊天展开默认使用 Enter，优先消费该按键，不继续进入同键的开火/确认动作；第一次展开不会提交回答。
此入口只在正常游玩且无其他输入所有者时启用；商店、结算、编辑器和实验菜单继续使用各自的确认操作。
上下键与滚轮浏览历史，当前剧情不提供选择、回答或继续按钮；聊天关闭时已按住的输入也经过同一释放边界。
终端与设备消费输入后，清除本帧业务输入和保留边沿，并记录已按住键/鼠标，直到释放后才重新向玩法开放。
窗口失焦清理保留状态。单人暂停菜单明确暂停；设备、终端与 RTS 不暂停世界。
切 FPS/RTS 保留选择与 session 移动目标，FPS 期间玩家手操，回到 RTS 后继续已有目标。

偏好写入独立版本文件 `rasterfall-ui-v2.cfg`，保存 mode/scale/opacity/hints/crosshair；
临时文件完整写入并关闭后原子替换，损坏输入不会覆盖现有有效内存设置。
保存失败每五秒重试，避免每个模拟步重复文件访问；退出仍做最后一次保存尝试。
剧情保存由故事模块单独拥有。制造与世界仍遵守原项目会话生命周期，不声称跨退出保存完整世界。

扩展新的业务动作先加结构化请求/查询及权威校验，再接终端和窗口。布局调整只改主题/布局描述符或面板，
不得把窗口焦点、展开状态或渲染资源写入 `toy_game`。新增故事只扩展节点/条件/事件和稳定 ID。
