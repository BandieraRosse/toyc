# 统一音频与本地混音

> 状态：当前
> 所有者：Rasterfall audio presentation
> 最近核对：2026-10-08

操作入口见[音频设置与验证](../guides/audio.md)。音频设备仍归 Core，唯一混音线程、声部、
音乐时钟、机器循环和 UI 振荡器归 `rasterfall_audio`。Game/session 只产生权威事件或可读状态，
音量、监听点、声像、限幅与试音不进入 Game、AI 或网络协议。

## 强度与分组

声源传播强度与输出响度分开。首版用几个强度档近似现实的相对关系：角色/交互属于短程声音，
普通枪械属于远程，狙击与爆炸传播更远。输出增益由资源种类单独校准，不直接按现实声压放大 PCM。
这些数值是游戏内部增益与距离，不代表耳机实际声压；RFU 换算见公共单位合同。

| 分组 | 内容 | 父控制 |
| --- | --- | --- |
| 音乐 | 现有程序循环音乐 | 总音量 |
| 游戏音效 | 换弹、空击、推搡、近战及各音效子组 | 总音量 |
| 枪械与爆炸 | 五类枪械、爆炸、燃烧瓶破裂 | 游戏音效 |
| 自身枪声 | 本地第一人称枪声及本地试音的附加衰减 | 枪械与爆炸 |
| 环境与机器 | 网格编织机循环及设备提示 | 游戏音效 |
| 战斗反馈 | 命中、击杀、受伤、死亡、炸弹提示 | 游戏音效 |
| 界面 | 悬停、点击、调整、确认、退出提示 | 总音量 |

每项 0–100 使用平方振幅曲线，100 对应校准增益，0 精确静音。默认标准动态范围；宽广保留
更多强事件峰值，舒适额外衰减枪械/爆炸并收紧效果总线峰值。预设不提升远处脚步或改变传播距离。
目前没有已接入的对白声音总线，也没有自动音乐状态切换。

`rasterfall_audio_engine.inc` 持有音效分类、资源 trim 和简化峰值映射。枪械相对旧整体音效增益
降低，狙击和爆炸另有峰值补偿；连射枪声在保留开头的同时衰减尾部。
`toy_sfx_render_buses` 输出宽整数音乐/音效累加器，机器与 UI 使用独立的有界 PCM 缓冲，再统一汇合。
效果与最终总线采用左右声道联动的软峰值保护，保持声像比例；总音量在最终保护之后作用于全部声音。
音量变化使用平滑增益并最终收敛到精确零。当前峰值映射是低成本近似，不是带包络的完整 HDR 或母带压缩器。
旧 `toy_sfx_play/render/render_gained` 保持默认合成、离线资源生成与原混音行为。

## 空间、来源与并发

主线程把声音事件投影为带来源、左右增益、优先级、本地标记和 world generation 的命令。
世界声像在触发时计算；短音播放途中不再次追踪声源。简单二次距离衰减、左右声像由
`rf_audio_spatial_gain` 统一实现，机器循环每帧更新同一监听点的增益。

FPS 监听点跟随玩家相机。RTS 把中心射线投影到当前关注楼层附近，以世界高度监听，避免
相机抬升或缩放导致战场整体静音。辅助镜头不增加第二路收听。当前没有墙体遮挡、混响、HRTF 或远近音色切换。

AI 射击由既有 fire sequence 去重后附带角色位置提交。网络角色射击由既有确认/展示序列
提交位置；协议中的无来源聚合事件不再重复播放枪声，其余反馈保留为非空间声音。
本地事件仍是第一人称反馈；没有位置的炸弹/燃烧瓶聚合事件也保留非空间播放，不伪造爆炸坐标。

同一来源最多叠加两条枪声；八声部满载时，低优先级声音不能替换更重要的声音，
同优先级优先替换剩余时间较短的声部。本地反馈优先于普通世界枪声，世界枪声根据空间增益排序。
固定事件环对远端/世界事件预留本地/UI 容量；饱和时有界丢弃展示声音，不回写玩法。

## 线程与生命周期

事件环为单生产者、单消费者，索引使用 release/acquire；配置由主线程保存，混音线程只读原子增益目标。
每个滑块独立发布，允许跨一个混音块观察到相邻设置的不同版本，不影响权威状态。
world generation 改变后清理旧一次性声部和待试音，忽略旧代际排队事件。
机器保留既有身份邮箱与暂停语义；远处仍观察任务变化，不在靠近时补播旧提示。

暂停菜单试音依次播放枪声与换弹，仅提交音频命令，不生成射击、伤害或换弹请求。
停止线程后才能释放资源。换图和 CPU/GPU 切换不会重新加载或重置主线程持有的音量偏好。
