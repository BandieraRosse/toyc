# 共享战斗、标准枪手与飞行子弹

> 状态：当前
> 所有者：确定性 Game / actor
> 事实入口：`rasterfall/lib/game_combat.inc`、`game_hitscan.inc`、`game_ballistics.inc`、`game_actor_ai.inc`、`game.c`；`rasterfall/include/toy_game.h`

## 标准步枪与冲锋枪

AK / SMG 的武器表及操作能力恢复至 `232e9f8` 的较早数值：移动扩大散布，连射累积热量，
精通影响射击间隔、换弹与热量，精准影响基础散布、瞄准和弱点收益。第一人称武器后坐演出
继续使用既有表现；飞行弹丸、三维命中、简化回避和固定步计时修复保留。
生命、移动与回避容量仍由角色模板决定；策略对抗双方采用相同 standard 模板。

数值来源为 `toy_game_config.h` 的武器表、`game_ballistics.inc` 的弹速/距离曲线及
`toy_game_actor_capabilities()` 的操作能力。当前工作值：

| 项目 | 步枪 AK | 冲锋枪 SMG |
| --- | --- | --- |
| 基础单发伤害 / 弹匣 | 16 / 40 | 7 / 40 |
| 机械间隔 / 射速上限 | 180ms / 约 333 RPM | 100ms / 600 RPM |
| 武器基础散布参数 | 50 | 90 |
| 弹速 | 720m/s | 400m/s |
| 伤害曲线距离点 | 30 / 45 / 65 / 90m | 15 / 25 / 40 / 60m |
| 对应伤害倍率 | 100 / 75 / 45 / 25% | 100 / 75 / 40 / 20% |
| 最大飞行距离 / 感知距离 | 17250 / 11500 RFU（约 33.7 / 22.5m） | 11500 / 8400 RFU（约 22.5 / 16.4m） |
| AI 瞄准准备 / 转身 | 按精准能力 | 按精准能力 |
| 基础换弹时间 | 2200ms | 2000ms |

首个距离点内为完整伤害，距离点之间线性插值，超过最大射程的距离点不参与实际命中。
最大飞行距离是硬上限，不能因为伤害曲线存在更远的距离点而延长弹丸寿命。
衰减按弹丸实际累计飞行距离计算，生命小数伤害与回避均保留毫点精度。
步枪偏向中距离，冲锋枪以较高近距离输出、较快开火准备和换弹响应体现近距离操作优势，
不赋予持枪额外跑速，也不承诺近距离静止对射必胜。上述是游戏工作值，不是现实枪械标定。

AI 只瞄准目标当前位置，不求提前量。换目标和移动清除瞄准准备；短于 200ms 的临时
射界/朝向丢失保留准备，但当步立即停止射击。持续丢失、死亡和 generation 变化清除准备。
射击间隔保留固定步余量，避免将机械及能力间隔长期向上量化。

`game_ballistics.inc` 在 Game 的 512 个有界弹丸槽中推进直线飞行，逐步扫掠墙体和当步
身体位置，防止高速弹穿过薄墙。角色移动可令已发射子弹落空；没有重力、弹道下坠或穿透。
发射与命中分别记录 FIRED / IMPACT，旧瞬时枪械记录 RESOLVED。事件只供统计与表现消费，
伤害不依赖特效。射手死亡不删除在途弹；移除、generation 变化取消旧弹，实验暂停冻结所属弹丸。
隔离 Game 预测复制这些弹丸及 RNG，不另用期望伤害推进世界。

FPS / RTS 共用相机无关飞行短弹迹：最长 4m、48ms 寿命，使用加宽的浅金色亮线。
本地正式弹丸、远端发射和命中末段使用同一表现参数；保持深度遮挡，不改变真实弹速、伤害或射程。
射速、散布和换弹结果受射手能力影响；理论输出不能替代包含瞄准、飞行、遮挡、连射散布
与未命中的靶场实测。

## 等级与技能

沿用 actor 的 `class_id`（0/1/2 对应 Lv1/2/3），不另存一份等级。个人 `skills.mastery` 保存
普通/掌握/精通/大师的 0/1/2/3 修正，最终档位为 `1 + 2 * class_id + mastery`，范围 1～8。
因此 Lv1 精通与 Lv2 普通、Lv1 大师与 Lv2 掌握完全等价。战斗只消费最终能力，不叠加等级倍率。
武器精通按手枪、冲锋枪、霰弹、步枪、狙击分别存储；移动、回避、耐力、精准各有独立修正。

`toy_game_actor_capabilities()` 是唯一参数映射。所有枪械的武器精通影响有效射击间隔、换弹和每发连射热量；
有效间隔始终不小于枪械机械间隔。精准影响基础散布、AI 转身/瞄准参数与弱点收益，绝不随机把身体命中改为爆头。
移动能力在 session 玩家移动及 AI 移动入口生效；耐力决定普通人形出生生命。
承载容量保留小型接口，目前没有护甲、背包和实际负重效果；回避与真实弱点已进入结算。

原玩家专属 200% 射速/60% 换弹，以及三级 AI 的 80% 射击间隔已移除。
人类玩家默认 Lv2，武器掌握、精准掌握、回避精通，其余普通，生命 120。
普通队友沿用三级等级，普通耐力对应 80/120/160 生命；剧情动漫队友使用 Lv3 机动模板和耐力精通，
生命由 190 调为 200，不降低现有队友生命来制造挑战。导演旧 CP 粗评分保留，不新增动态综合战力系统。

能力由主机 actor 真值拥有。当前协议的 actor snapshot 包含精通、max_hp、阵营、generation、回避及战斗统计，客户端不再按外观猜测生命上限。
本地玩家、AI 及可信客户端 reported fire 都使用共享武器射击/换弹计时；表现层只读取能力。
lower/upper/additive、资源、socket 和 IK 仍属于[角色表现](character-presentation.md)与[动画架构](animation-architecture.md)。

## 阵营、决策与射击

玩家和队友为 ALLIED，普通/精英枪手为 HOSTILE；二者互相敌对，感染者攻击两个人形阵营。
枪弹和斧头保持无友伤，枪弹穿过同阵营身体。燃烧只伤敌方人形及感染者；炸弹保留原玩家受伤、
友方 AI 仅击飞的政策，并使敌方 AI 正常受伤。developer_only 展示对象不参与枪战目标。

`game_actor_ai.inc` 共用感知、转向、瞄准准备和 actor 命令执行。每 actor 250ms 扫描一次，
全体每逻辑步最多八次目标查询；每次在有效射程内按真实可见性与距离选择目标。缓存记录 generation，
slot 复用或死亡立即使目标失效。普通自主敌方沿用武器交战距离带、近身后退，失去视线只追最后
观察位置最多 1.5s；队友仍服从部署/跟随命令。没有额外阵营伤害倍率，也不新增掩体规划。

普通 AI 的同一次感知扫描对当前有效可见目标使用小幅距离迟滞：当前身份的距离平方权重为 4，
其他候选为 5。近等距敌人交替变为最近时不反复重置瞄准；明显更近的敌人仍可替换当前目标。
实际感知范围单独校验，死亡、槽位复用、阵营、守区和遮挡过滤不受迟滞影响；身份失效立即清除，
失去可见性的目标在下一次正常扫描中释放，逐步射击仍需原可见性检查。每候选至多一次 LOS 查询，
不增加扫描次数或第二轮可见性查询。公开 `toy_game_find_combat_target()` 仍返回最近可见目标，
本地玩家 RTS 保持原选择行为；保留目标不改变友军 RTS 移动意图，也不修改枪械、能力或弹药参数。

任务枪手可以由 `toy_game_actor_set_guard()` 设置以部署点为中心的守区半径：仅感知该圆内的
真实可见敌人，最后观察位置和退让目的地也受守区限制；没有目标时回到岗位。增援通过
`toy_game_actor_set_assault()` 设置部署目的地，没有目标时继续进场，有目标时沿用普通交战规则。
这两个意图只属于主机 Game 的敌方 AI，不覆盖友军已接受的 RTS 移动/停止命令。
有目标时，正常交战距离内的枪手以当前位置为移动目标，不反复返回部署点而抵消上一步追击。
较远目标仍触发追击，近身目标仍触发退让；目标丢失后沿用最后观察位置的期限，随后正常返岗或继续进场。
此 hold 不保存额外追击状态、不增加迟滞参数或规划查询；各武器距离带、守区和实际碰撞保持原规则。
感染者生成也拥有 `combat_generation`，枪手缓存其槽位时同时验证 generation，死亡后的槽位
复用不能继承瞄准进度。任务追踪使用同一身份合同，不以全局击杀数代替成员存活状态。

普通感染者每500ms（16ms固定步下512ms）重选一次目标；当前有效人形身份按距离平方4、
其他候选按5使用小幅迟滞，减少近等距目标切换导致的门口追击摇摆。先选择具有原始2400RFU
直接物理通路的候选，再沿用原共享目标场，迟滞不能使墙后目标压过直接可达目标。
`target_generation` 将普通追击缓存绑定到被追人形的生存期；0是未绑定，死亡、inactive、
地域或generation失效当步重选并清直达缓存。特感仍按原最近目标规则；高度、可达性、
碰撞、感知规则和每步寻路预算不变，也没有追加候选扫描或BFS。该主机缓存不增加snapshot字段。

`game_hitscan.inc` 共用三维箱体/斜坡遮挡、射程、水平散布和垂直高度命中。人形头部为真实命中高度
达到身体 84% 的区域，精准只改变该命中的收益；感染者沿用全身同伤害。
玩家 session 在处理本步视角输入后同步 actor 的水平朝向与俯仰角，开火使用这一份当前方向；离线和客户端预测一致。主机接收远端相机报告时也同步俯仰角，不复用出生时的水平射击方向。
`toy_game_actor_begin_fire()` 拥有弹药、机械/技能时序和换弹；`toy_game_actor_resolve_shot()`
按攻击—目标聚合命中的弹丸。旧瞬时枪械沿用可信 reported-ray 结算。AK / SMG 的可信输入只报告采样方向，主机验证
武器时序与包边界后创建正式飞行子弹；客户端不预测其人形或感染体伤害。
主机确认的发射/命中事件驱动客户端视觉回放，详见[联机架构](network-architecture.md)。

普通 AI 与枪手装备时获得武器表的真实弹匣和 `reserve_max`，换弹逐发扣除备弹；备弹与弹匣
耗尽后不能继续射击。手枪沿用正式无限备弹规则，基地核心等明确的固定防御对象保留自己的
政策。普通 AI 不会自动生成弹药或访问补给点；任务中的补给必须走可见的正常拾取/交互规则。

## 队友救援

普通友方 AI 在约 11.7m 内选择最近倒地友军，包括本地玩家；每个倒地身份同时只由一名 AI
领取救援意图，索引和 generation 共同验证。没有 RTS 命令时可走近救援；已接受命令的队员先
完成移动，之后只允许对交互距离内的友军原地救援，不离开命令岗位。新 RTS 命令调用
`toy_game_actor_cancel_rescue()` 清除旧意图和进度。

救援进入约 2m、同支撑高度且真实可见的距离后，逐固定步调用正式 `toy_game_revive_actor()`；
进度、复活生命和控制清理仍归该入口。受伤、近距离可见敌人、空中/特殊控制、剧情 hold 或
身份变化会中断。救援期间不射击，武器计时正常推进；远处敌人不会要求整张地图绝对安全。
展示角色、基地核心与敌方枪手不参与此友方救援策略，运行时与 HUD 不另行推进复活。

## 连续回避和伤害顺序

储备使用千分之一伤害单位，档位 1～8 上限为 0/0/45/65/90/110/130/150，
每秒恢复 0/0/10/12/14/16/18/20。玩家 120HP/90回避；普通枪手 100HP/0；
精英枪手 120HP/65。基础队友仍由等级决定，机动专长可在低等级提前解锁。
基地核心不属于人形回避对象，容量与恢复均为零。

1. 先确定实际几何命中和遮挡，未中弹丸没有成本。
2. 枪弹、咬伤和斧头均按实际基础伤害消耗储备，弱点倍率不增加成本。
3. 按 `min(储备, 成本) / 成本` 覆盖攻击份额，剩余份额乘部位倍率进入生命。
   例如 60 伤害命中身体、储备只有 15，剩余 75% 造成 45HP。
4. 取消优惠窗口和近战额外倍率。侧身动画与 1200ms 再触发间隔只控制表现，
   没有额外免伤、散布惩罚、移动加速或位置变化。
5. 每次有效受击重置可配置的恢复等待，默认 3000ms；等待结束且未被控制才恢复。
   生命伤害的小数余量积累，避免舍入带来永久免伤。

一次霰弹只对真正命中的目标汇总成本与部位伤害，每目标最多一次动作事件；回避消耗、真实掉血、
过量伤害分别统计。V0 无护甲，因此 armor_absorbed 为零。射速、储备与伤害只按固定逻辑步长更新，
HUD/特效读取结果，不用渲染帧时间参与结算。

Smoker 的连接和多重牵引仍归原状态机；牵引伤害直达生命，外部普通攻击仍可回避，动作不解除连接。
Charger、Tank 冲击/范围、炸弹、燃烧绕过储备；原冲击去重、强制位移、冷却保留。
死亡清空储备/窗口/动作/目标并解除自身控制；既有击飞仍推进到落地，AI意图和射击不会继续。
落地仅释放普通冲击控制，不清活跃Smoker状态。主机、本地及远端救援统一通过 revive 入口，
清除旧击飞/控制并恢复 `min(100, max_hp)` 生命。复活和实验复位调用同一 combat reset，恢复代表模板储备。
reset 不偷偷修改位置、阵营、HP、弹药或既有强制位移，调用方负责完整场景生命周期。

## 平衡与验证边界

本轮只重新标定 AK / SMG；其他武器和感染体的既有生命、伤害数值继续沿用。
全局回避成本简化会影响近战持续消耗，不能拿旧优惠窗口下的存活时间直接比较。
理论机械 DPS 不代表几何命中、衰减、瞄准与换弹后的有效输出；靶场同时记录发射、
命中、实际生命伤害、回避消耗和 TTK。新规则结果不得与旧训练文件混用。

历史平衡与技能原型见[V0 现场](../archive/combat-v0-20261003.md)；本轮验证见
[标准枪手与难度分层现场](../archive/combat-ai-20261008.md)。
